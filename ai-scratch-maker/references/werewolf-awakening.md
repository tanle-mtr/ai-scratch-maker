## §394 「觉醒」不是加强版，是一次机制改写

最容易犯的错，是把觉醒角色当成「原角色 + 数值变大」来实现：
血量 +1、查验次数 +1、带人数量 +1。这样写出来的作品**规则一定错**。

看一眼官方的改法就明白了：

| 原型 | 直觉上的「加强」 | 官方实际做的事 |
|---|---|---|
| 预言家 | 每晚验 2 人 | 每晚**选 2 人只问「其中有没有狼」**（信息从「具体阵营」降成「集合查询」） |
| 女巫 | 多一瓶毒 | 毒药改成**必须 1/2/3 名协助者全票同意**才生效（引入协商与不信任） |
| 猎人 | 能带 2 人 | 改成**正序/逆序巡猎最近的狼**（必中狼，但目标不可选） |
| 骑士 | 决斗更稳 | 决斗到好人**双方一起出局**，决斗到狼**可以连击**（风险与收益同时放大） |
| 狼王 | 出局带 2 人 | 两次「狼王爪」变成**可以夜里亲传给队友的资源** |

**结论：觉醒 = 换掉原技能的一个「约束维度」，而不是放大数值。**
常见被换掉的维度有五种：

```
① 作用时机：夜晚 → 也可白天（觉醒守卫、觉醒骑士、觉醒白狼王）
② 作用对象：自己 → 可转移给他人（觉醒狼王亲传、觉醒愚者秘密之身）
③ 信息来源：单人 → 集合 / 多人协商（觉醒预言家、觉醒女巫）
④ 结果方向：保护 → 攻击（觉醒摄梦人梦语出局）、被动 → 主动（觉醒隐狼模仿）
⑤ 阵营归属：固定 → 可变（觉醒石像鬼转化者、觉醒孤独少女变身）
```

因此**实现觉醒角色时不要复用原型的脚本再加一个次数变量**。
正确做法是：把原型和觉醒当作**两个不同的身份编码**，各自挂各自的判定脚本，
只共享通用的「死亡结算 / 胜负 / 警徽流」骨架。

> ⚠️ 第三十三册 §322 说「每个身份四要素：阵营 / 触发窗口 / 目标合法性 / 结算时点」。
> 觉醒角色还需要**第五要素：状态可变性**（阵营会不会变、技能会不会转移、会不会消耗）。
> 少了这一项，觉醒石像鬼和觉醒孤独少女一定写错。

## §396 好人觉醒（一）：查验与药剂

### 觉醒预言家（寻香识命）

> 每天晚上可以选择任意两名玩家窥视其身份，从而判断**其中是否有狼人**。

- 触发窗口：夜间查验位（第三十三册 §342 第 9 位）。
- 输入：两个不同的玩家号 `a, b`（**必须校验 `a ≠ b`**）。
- 输出：**一个 bit**「有狼 / 无狼」，不是两个人的阵营。
- 关键：`有狼 = (阵营(a)=狼) OR (阵营(b)=狼)`，用的是**变形后的阵营**
  （第三十三册的「隐形狼位掩码」在这里仍然生效）。

```
# 平行列表：验人A / 验人B / 结果(0无狼 1有狼)
广播 [觉醒查验]
  若 a = b → 结果 = -1（非法，重选）
  否则 结果 = (阵营表[身份池[a]] = 1 或 阵营表[身份池[b]] = 1) ? 1 : 0
```

⚠️ 常见错：给两个目标各存一个「金水/查杀」。这会把**集合查询**退化成两次单验，
信息量翻倍、板子直接失衡（寻香识命板子靠的正是「知道有一狼但不知道是谁」）。

### 觉醒女巫（觉醒女巫 / 沙龙之夜）

> 解药救被狼刀者，或用毒药调配使一人出局；**同一晚只能二选一**。
> 一局可用 **3 次**毒药调配；第 1/2/3 次分别需 **1 / 2 / 3 名协助者**。
> 协助者夜间可交流、**全员同意才生效**；女巫**不知晓**协助者的选择结果。
> **每名玩家每局只能参与协助一次**。

这是整个觉醒体系里唯一引入**多人协商**的技能，实现上有四张表：

```
毒药次数     = 0..3                  # 已用次数，也决定本次需要几名协助者
协助者表     = [玩家号, ...]          # 长度 = 毒药次数 + 1
协助票箱     = [0/1, ...]            # 与协助者表平行，1 = 同意毒
协助过表     = 每人 0/1              # 全局唯一性守卫，永不重置

判定：生效 = (毒药次数 < 3)
          AND (协助者表长度 = 毒药次数 + 1)
          AND (协助者两两不同 AND 均存活 AND 协助过表[每人] = 0)
          AND (票箱全为 1)
生效后：毒药次数 += 1；把协助者表逐项写入 协助过表 = 1
```

⚠️ 四个必须写进校验的边界：
1. **协助者不能是毒药目标本人**（否则会出现「投自己被毒」）。
2. **协助过表是全局的**，不是每晚清空 —— 官方明确「每局只能参与协助一次」。
3. 女巫**看不到票箱**：UI 只显示「调配完成」，结果在次日出局信息里揭晓。
4. 解药与毒药**互斥**，一晚只准一个；别做成两个独立开关。

## §397 好人觉醒（二）：守护与免伤

### 觉醒守卫（月坠光渊 / 觉醒骑士）

> 每天可选在**夜晚**或**白天放逐发言阶段**使用一次觉醒守护，
> 被守护者**不会以任何方式出局**；每天 1 人，不能连续两天同一人。
> 夜里守护 → 效果持续到**下一天白天结束**；白天守护 → 持续到**当天白天结束**。
> 被守护者白天被放逐 → **直接免疫放逐、显示平安日、无遗言、直接进入夜间**。

与原型守卫的三处不同（都会改判定链）：

| | 原型守卫 | 觉醒守卫 |
|---|---|---|
| 作用阶段 | 仅夜间 | **夜间 + 白天** |
| 免伤范围 | 仅狼刀（会被毒/枪穿） | **任何方式出局**（含放逐、自爆、技能） |
| 同守同救 | 奶穿 → 出局 | **不存在奶穿**，守护是最高优先级免疫 |

实现要点：把「觉醒守护」放在**死亡结算链的最外层**（第三十三册 §343 第 0 步，
在「免疫含奶穿」之前）：

```
结算出局(玩家 p, 死因 d):
  若 守护标记[p] = 1:
      若 d = 放逐: 广播 [平安日]; 遗言 = 无; 直接入夜; return   # 特殊分支
      否则: 免疫; return                                    # 含自爆/毒/枪/技能，全挡
  ... 其余免疫链不变（守卫/解药/流光庇护/秘密之身 ...）
```

`守护标记[p]` 的**有效期必须带阶段时钟**，不能只用一个布尔：
```
守护到期 = (守护阶段, 守护日)   # 夜里守 → (白天结束, 次日)；白天守 → (白天结束, 当日)
每次跨阶段时统一清一次到期标记
```
另外「连续两天不能同一个人」要存 `上次守护目标` + `上次守护日`，
**比较的是「日」不是「夜」**（白天守也算那一天）。

⚠️ 最容易漏的是「平安日」：被守护者被投出局时，
不是简单地把人留下，而是**本白天整个遗言阶段被取消、直接入夜**。
只免疫不跳过流程，会让玩家多一轮发言，轮次算错。

### 觉醒愚者（觉醒之夜）

> 拥有**秘密之身**：白天被放逐时翻牌并免疫本次放逐，且失去秘密之身。
> 夜间可用秘密之身保护一名玩家，**尝试为其抵消一次今夜受到的伤害**；
> 若目标未受伤或已被救，则改为替**自己**抵消一次伤害。
> **不论为谁成功抵消一次伤害，都会失去秘密之身。**

状态只有两个：`秘密之身 = 0/1`、`今夜保护目标 = 玩家号`。
判定必须放在夜间结算的**最后一步**（在解药、守护、流光庇护之后）：

```
夜间收尾:
  p = 今夜保护目标
  若 秘密之身 = 1 且 p 今夜受到过 ≥1 次伤害且未被其他手段救活:
        抵消其中 1 次; 秘密之身 = 0
  否则若 秘密之身 = 1 且 觉醒愚者自己今夜受到过 ≥1 次伤害:
        抵消自己 1 次; 秘密之身 = 0
  # 目标没受伤 / 被女巫救了 / 两人都没事 → 不消耗，秘密之身保留
```

官方补充的六条边界（照抄进校验）：

| 情形 | 结果 |
|---|---|
| 目标受 **2 次**伤害 | 只抵消 1 次 → 目标仍出局，秘密之身消耗 |
| 目标被狼刀但**女巫用解药救了** | 女巫拿到的是「出局信息」不是平安夜；秘密之身**没有**抵消、**不消耗** |
| 愚者与目标**同夜各受一次伤害** | 优先保目标 → 愚者自己出局 |
| 愚者是**警长**且带身被放逐 | 翻牌免放逐，**不必移交警徽**，仍保有投票/被投票权 |
| 对**猎魔人**用秘密之身，猎魔人当夜狩猎到好人 | 次日猎魔人不出局，秘密之身消耗 |
| 失去秘密之身后再次被放逐 | **不翻牌**，正常出局 |

> 注意「对猎魔人用秘密之身」这条：说明秘密之身抵的是
> **「技能反噬」这类非伤害型出局**，所以判定条件应写成「今夜该玩家被判定出局」，
> 不要写成「受到狼刀」。

## §398 好人觉醒（三）：出局与决斗

### 觉醒猎人（暗夜星辰）

> 出局后可选**正序或逆序**发动巡猎，使该方向**最近的一名狼人**出局。
> 若觉醒猎人在**夜间**出局，被巡猎的特殊狼人**技能无效**。

与原型猎人「任意选一人开枪」完全不同：这是**沿座位方向的搜索**。

```
巡猎(起点 s, 方向 d ∈ {+1,-1}):
  k = s
  重复 玩家数 次:
      k = ((k - 1 + d + 玩家数) mod 玩家数) + 1      # 环形，1-based
      若 存活表[k] = 1 且 阵营表[身份池[k]] = 1:    # 只找存活的狼
          出局(k, 死因=巡猎); return k
  return 0        # 场上没狼了 → 空枪，不要报错也不要打自己
```

⚠️ 三个坑：
1. **必须环形取模且跳过出局者**，否则扫到边缘就停、或打到死人。
2. `死因=巡猎` 要新开一个编码；复用「枪」会让被带走的狼王错误地能开技能。
3. 「夜间出局时特殊狼人技能无效」是**独立开关**：
   `若 昼夜=夜 且 死因=巡猎 → 被带走者.技能封锁 = 1`，
   要在死亡结算的「触发式」那一步之前写入（第三十三册 §343 第四步）。

### 觉醒骑士（觉醒骑士，收官之作）

> 白天放逐发言阶段随时翻牌，**选一位玩家决斗**。
> 决斗到**狼** → 狼出局，骑士可**选择是否继续决斗**；不继续 → 全部出局者遗言后**入夜**。
> 决斗到**好人** → **骑士与对方同时出局**，全部出局者遗言后**继续原本白天发言流程**。
> **每名玩家只能被决斗一次**。

这是全套里状态机最复杂的一个，因为「入夜 / 继续白天」取决于决斗结果：

```
状态: 决斗已用表[玩家] = 0/1 ; 连击开关 = 0/1 ; 本轮出局队列 = []

决斗(骑士 r, 目标 t):
  若 决斗已用表[t] = 1 → 拒绝
  决斗已用表[t] = 1
  若 阵营[t] = 狼:
      出局(t, 死因=决斗)
      询问骑士「继续?」→ 是: 回到选目标 ; 否: 遗言(本轮出局队列) → 入夜
  否则:
      出局(t, 死因=决斗); 出局(r, 死因=决斗)
      遗言(本轮出局队列) → 继续白天发言流程（不跳过、不入夜）
```

⚠️ 与**原型骑士**的对照最容易写反：

| | 决斗到好人 | 决斗到狼 |
|---|---|---|
| 原型骑士 | 骑士自己出局，**继续白天发言** | 狼出局，**立即入夜** |
| 觉醒骑士 | **双方都出局**，继续白天发言 | 狼出局，**可选连击**，主动停手才入夜 |

即「好人方代价更大、狼人方收益更大」。另外**连击上限不是无限**：
官方写「每名玩家只能被决斗一次」，所以最多连到场上玩家数；
且骑士一旦决斗到好人自己也出局，连击立即终止。

## §399 好人觉醒（四）：梦语与昼夜

### 觉醒摄梦人（觉醒摄梦人 / 沙龙之夜）

> 每晚**必须**选一名玩家成为**梦语者**；梦语者不知道自己在梦语，且**免疫夜间伤害**。
> 觉醒摄梦人在**当晚最后阶段**得知梦语者**是否行动**。
> 从**第二夜**开始，在确认梦语者是否行动时可选择**是否将梦语者梦语出局**。
> **两晚不能连续梦语同一目标**。

三件事被原型反转了：

| | 原型摄梦人 | 觉醒摄梦人 |
|---|---|---|
| 梦游者知情 | 不知道 | 不知道（同） |
| 夜间伤害 | 免疫 | 免疫（同） |
| 连续两晚同目标 | → 目标出局 | → **非法，必须重选** |
| 摄梦人出局 | 梦游者一并出局 | **无此连带** |
| 主动权 | 无 | **第二夜起可主动梦语出局** |
| 信息 | 无 | 当晚末得知「目标是否行动」 |

「是否行动」是一条**用来分辨闭眼玩家的情报**：夜里睁眼放过技能的玩家会「行动」。
实现上给每人一个 `今夜行动` 标志，所有夜间技能发动时置 1，
当晚队列最后一位（第三十三册 §342 的「收尾」）把它读给觉醒摄梦人、然后统一清零。

```
数据: 梦语者 / 上夜梦语者 / 今夜行动表 / 夜数
夜间开局: 必选 梦语者 ≠ 上夜梦语者（否则拒绝重选）
夜间伤害结算: 若 目标 = 梦语者 → 免疫
夜间收尾队列最后:
    情报 = 今夜行动表[梦语者]           # 只给觉醒摄梦人看
    若 夜数 ≥ 2 且 摄梦人选择「梦语出局」:
        出局(梦语者, 死因=梦语)         # ★ 不是「夜间伤害」！
    上夜梦语者 = 梦语者
    清空 今夜行动表
```

⚠️ **最关键的一条**：梦语出局是**技能结算**，不是夜间伤害。
如果把它走「夜间伤害」通道，会被梦语者自己的「免疫夜间伤害」挡掉，
表现为「技能按了没反应」——这是这类「自带免疫 + 主动出局」角色的通用坑
（同理见觉醒守卫：免伤不能挡自己的技能）。

## §400 狼人觉醒（一）：技能可转移

### 觉醒狼王（觉醒狼王 / 觉醒女巫）

> 参与夜间讨论与行动，可自刀、可自爆。拥有**两次狼王爪**。
> 可选择在夜晚把**一次**狼王爪**亲传**给任意存活狼队友。
> 拥有狼王爪者出局后可选一名玩家一并带走。
> **不亲传**则被放逐出局时能直接发动**两次**狼王爪。

「狼王爪」是**资源**，不是布尔标志。这是全套 13 个角色里最容易实现错的一个：

```
狼王爪持有表[玩家] = 0/1/2      # 每人持有几个爪，不是「是不是狼王」
狼王爪总数 = 2                  # 全局守恒，亲传只减不增

亲传(觉醒狼王 w, 队友 t):    # 只能夜里、只能传狼队友、只能传 1 个
  若 狼王爪持有表[w] ≥ 1 且 存活[t]=1 且 阵营[t]=狼:
      狼王爪持有表[w] -= 1
      狼王爪持有表[t] += 1        # ★ 转移，不是复制
      亲传已用 = 1                # 官方只允许亲传一次
  # 校验不变量：sum(狼王爪持有表) 恒 = 2

出局结算(p):
  n = 狼王爪持有表[p]
  若 n > 0 且 存活狼数 > 1:       # ★ 最后一狼时不能发动
      重复 n 次: 选一名玩家 → 出局(死因=狼王爪)
  狼王爪持有表[p] = 0
```

官方对不同出局方式还有细则（放逐 / 刀杀 / 枪杀 / 凝视出局都可发动；
**亲传全部爪后自己出局不能发动**），统一用上面「持有数」模型就能自然成立，
**不需要为每种死因写分支** —— 这正是「资源模型」比「状态标志」好的地方。

⚠️ 别写成 `狼王 = 玩家号` 一个变量。亲传之后场上会有**两个**能带人的狼，
用单变量必然丢一个；而且「最后一狼不能发动」需要现算 `存活狼数`。

### 觉醒隐狼（镜隐迷踪 / 云端追踪）

> 夜间不参与狼队讨论与行动、不能自爆、**与其他狼人互不知身份**；
> 其余狼人出局后可夜间袭击。
> 可选一名玩家**模仿**：**立刻获得目标身份**，**当夜结束后获得目标技能**。
> 模仿狼人 → 加入狼队并获得**一次性额外狼刀**；
> 模仿魔镜少女 → 每晚验具体身份；模仿女巫 → 一瓶毒；
> 模仿守卫 → 每晚守护（防狼刀和毒）；模仿猎人 → 出局带一人。

「立刻获得身份 / 当夜结束才获得技能」是**两阶段**的，必须拆开：

```
模仿目标 = t
阶段①（当夜立即）: 显示身份表[自己] = 身份表[t]     # 影响查验结果与可见性
阶段②（当夜收尾）: 技能表[自己] = 技能表[t]        # 次夜起才可用
                    若 身份[t] = 狼 → 额外狼刀 = 1（一次性）
```

⚠️ 三个边界：
- 模仿**狼人**时「加入狼队」会改可见性位掩码（第三十三册 §329），
  但**额外狼刀是一次性的**，用完要清零，不是每夜都有。
- 模仿**女巫**只有一瓶毒、没有解药（官方只写毒药）。
- 模仿**守卫**的守护能挡女巫毒药，比原型守卫强；别直接复用原型脚本。

## §401 狼人觉醒（二）：替死与转化

### 觉醒狼美人（暗夜星辰 / 觉醒骑士）

> 不能自爆、不能自刀。夜里单独睁眼发动**挽歌幻象**魅惑一人。
> **第一次面临出局时，被魅惑者「替代」其出局**。
> 每隔一晚可发动一次，**只生效一次**。

与原型「出局时魅惑者殉情（连带）」完全不同：这里是**替死（免疫 + 转移）**。

```
数据: 幻象目标 = 0 ; 幻象已用 = 0/1 ; 上夜发动 = 夜数
夜间: 若 夜数 - 上夜发动 ≥ 2 且 幻象已用 = 0 → 可选目标
出局结算(觉醒狼美人 p, 死因 d):
  若 幻象目标 > 0 且 存活[幻象目标]=1 且 幻象已用 = 0:
      幻象已用 = 1
      出局(幻象目标, 死因=替死)        # 替死者出局
      return「p 免疫本次出局」           # ★ 自己活着
  否则 正常出局
```

⚠️ 替死要放在死亡结算链的**最外层**（和觉醒守护同层），
并且 `幻象已用` 必须在**判定当帧**就置 1，否则同夜多个伤害会触发多次替死。
另外「每隔一晚」是**夜数差 ≥ 2**，不是「隔一天」，别用白天计数。

### 觉醒石像鬼（觉醒石像鬼 / 觉醒摄梦人 / 风声谍影）

> 可自爆、可自刀。第一夜参与行动后单独睁眼，
> 选**狼人阵营相邻**的一名玩家成为**转化者**，**转化者阵营变为狼人**。
> 转化者**不与狼队见面、不能自爆**；其余狼人出局前可**正常使用原有技能**；
> 其余狼人全出局后，转化者**失去原有技能**，改为夜间袭击。

这是全套唯一会**中途改写别人阵营**的角色，需要三份数据而不是一份：

```
身份池[p]      = 原始身份（永不变，用于查验/技能）
现阵营表[p]    = 1狼/2神/3民/4第三方   ← ★ 胜负判定与阵营查询一律读这个
见面标志[p]    = 是否进狼队频道
转化者标记[p]  = 0/1 ; 转化者原技能有效 = 0/1
```

**关键设计**：第三十三册的身份表里「阵营」是写死在 `阵营表[身份编码]` 的，
觉醒石像鬼一出现就必须**再加一层 `现阵营表`**，
让所有阵营查询走 `现阵营表[p]`，`阵营表[身份]` 只作为初始化来源。
否则转化者在查验、屠边统计、胜负判定里会出现三套不同答案。

```
转化(t):
  若 t 与某个狼人座位相邻（环形座位 ±1）且 现阵营[t] ≠ 狼:
      转化者标记[t] = 1 ; 现阵营表[t] = 1 ; 见面标志[t] = 0
      # 注意：身份池[t] 不变，原技能继续可用
每夜入夜:
  若 存活狼数(不含转化者) = 0:
      转化者原技能有效 = 0 ; 见面标志 = 1 ; 获得夜间袭击
```

⚠️ 与红狼「野孩子 / 洞悉长老」的坑同源：
**阵营变了但身份没变**，所以「预言家查验」看到的仍是原身份，
而「屠边统计」算的是现阵营。两者不一致是**规则本身如此**，不是 bug。

## §402 狼人觉醒（三）：连锁自爆

### 觉醒白狼王（月坠光渊，2025 周年庆）

> 可自爆、可自刀、参与夜间讨论。
> **白天放逐发言阶段**可**诱导**一名当前存活玩家自爆出局；
> 被诱导出局者可**再选一名玩家**与自己一并出局。
> **发动诱导技能后双方均有遗言**。
> 可诱导狼人阵营玩家（含自己），且以此方式出局的狼人**不会翻牌**。
> **每局仅一次**。

这是「自爆」机制（第三十三册 §339）的一个新变体，要扩死因码：

```
死因码扩: 1 狼刀 / 2 放逐 / 3 毒 / 4 枪 / 5 殉情 / 6 技能
          7 自爆 / 8 被诱导自爆 / 9 被诱导连带 / 10 巡猎 / 11 决斗
          12 梦语 / 13 狼王爪 / 14 替死 / 15 夜仆

诱导(发起者 w, 目标 t):
  若 诱导已用 = 0 且 白天阶段 = 放逐发言 且 存活[t] = 1:
      诱导已用 = 1
      出局(t, 死因=被诱导自爆)
      若 t 选了连带对象 u: 出局(u, 死因=被诱导连带)
      遗言队列 += [t, u]                 # ★ 双方都有遗言
      if 现阵营[t] = 狼 → 翻牌 = 否      # ★ 狼被诱导不翻牌
      中止发言 → 跳过投票 → 直接入夜
```

⚠️ 与原型白狼王的区别：

| | 原型白狼王 | 觉醒白狼王 |
|---|---|---|
| 触发 | **自己**自爆时带一人 | **诱导别人**自爆 |
| 连带 | 1 层 | **2 层**（被诱导者再带一人） |
| 遗言 | 自爆者 30 秒 | **双方均有遗言** |
| 时机 | 自爆时 | **白天放逐发言阶段** |
| 次数 | 一次性 | 每局一次（同） |

另外「被诱导自爆」≠「自爆」：
- 它**不会触发血月使徒的封印好人技能**（那是主动自爆才有的）；
- 也**不算狼队主动自爆**，所以不进「双爆吞警徽」的计数。
死因码分开存就是为了这两条，别复用 7。

## §403 可变阵营：觉醒孤独少女（分叉状态机）

> 第一夜开始选一名玩家成为**偶像**。
> 若偶像**被放逐出局** → 觉醒孤独少女**变身为狼人**，每晚参与狼队行动，**胜利目标改为狼人**。
> 若偶像因**放逐以外的原因**出局 → **学习偶像技能、继承偶像身份**，胜利目标与继承身份相同。

一个角色、两条完全不同的分支，分支条件是**偶像的死因**：

```
数据: 偶像 = 玩家号 ; 变身状态 = 0未定/1变狼/2继承
事件「偶像出局」(死因 d):
  若 d = 放逐:
      变身状态 = 1
      现阵营表[自己] = 1 ; 见面标志 = 1 ; 获得夜间袭击
      # 身份池不变（仍显示觉醒孤独少女），但阵营与目标已变
  否则:
      变身状态 = 2
      身份池[自己] = 身份池[偶像]        # ★ 覆盖身份，连技能一起继承
      现阵营表[自己] = 阵营表[身份池[偶像]]
      # 继承的技能状态要跟着偶像走：偶像用掉的解药/毒药不能重置
```

⚠️ **四个致命点**：
1. **结算优先于变身**。偶像出局的那一帧要先跑完胜负判定，
   再处理变身；顺序反了会出现「刚变狼就赢 / 刚继承就赢」的假结算
   （与第三十五册红狼「野孩子」完全同一个坑）。
2. 「胜利目标改变」必须读 `现阵营表`，不能用 `阵营表[身份池]` 硬取。
3. 继承技能要**继承状态**（药水剩余、一次性技能是否已用），
   不能给一套全新的 —— 否则等于凭空多一瓶毒。
4. 偶像**一直没死**时，觉醒孤独少女始终是独立第三方牌，
   胜负判定要按第三方处理（第三十三册 §344 的优先级）。

> 与原型孤独少女（丘比特奇缘 / 孤独少女板子）的区别：原型是「偶像死了就变狼」，
> 不分死因；觉醒版**按死因分叉**，且多出「继承身份」这一支。
> 别把两者做成同一个身份编码。

## §404 原型 → 觉醒对照表：解除的到底是哪个限制

这张表是**设计新觉醒角色 / 核对实现**时最有用的一页。

| 原型 | 原型的限制 | 觉醒解除 / 改写成 | 副作用（必须一起实现） |
|---|---|---|---|
| 预言家 | 一次验 1 人、给具体阵营 | 一次 2 人、只答有无狼 | 信息模糊，无法指认具体人 |
| 女巫 | 自己决定用毒 | 1/2/3 名协助者**全票**才生效 | 女巫看不到票、每人每局只协助一次 |
| 猎人 | 任意选人开枪（可能打好人） | 正序/逆序找**最近的狼** | 目标不可选；夜死时封对方技能 |
| 守卫 | 只守夜间、只防狼刀、会同守同救 | 可守白天、**免一切出局** | 连守限制跨「日」；放逐触发平安日 |
| 愚者 | 翻牌免放逐但失去投票权 | 秘密之身**可给他人**抵一次出局 | 抵一次就消耗；被救则不消耗 |
| 摄梦人 | 被动、连梦两晚会杀人 | 可**主动**梦语出局、末位得情报 | 连梦同目标改为非法；不再有连带 |
| 骑士 | 决斗好人自己死、决斗狼立刻入夜 | 决斗好人**双死**、决斗狼**可连击** | 每人只能被决斗一次；停手才入夜 |
| 狼王 | 出局带 1 人、技能绑在本人 | 2 个**可亲传**的狼王爪 | 最后一狼不能发动；全局守恒 2 |
| 隐狼 | 固定隐藏、验为好人 | 主动**模仿**获得身份与技能 | 两阶段生效；额外狼刀一次性 |
| 狼美人 | 出局时魅惑者**殉情** | 第一次面临出局时**替死** | 隔夜才能再选；只生效一次 |
| 石像鬼 | 单独查验、最后才带刀 | **转化**一名相邻好人为狼 | 转化者不见狼队、保留原技能 |
| 白狼王 | 自爆时带 1 人 | **诱导**他人自爆，可 2 层连带 | 双方有遗言；狼被诱导不翻牌 |
| 孤独少女 | 偶像死 → 变狼 | **按死因分叉**：放逐→变狼，其他→继承 | 继承要带技能状态；结算优先 |

**规律**：几乎每个觉醒都在把「一次性 / 绑定本人 / 只在一个阶段」的东西，
改成「可转移 / 可协商 / 跨阶段」。所以实现清单里最该先加的，
是**「资源表」和「现阵营表」两张新表**，而不是给原型脚本加次数。

## §405 四类新增状态维度（超出第三十三册的七类分法）

第三十三册 §321 按「触发时机」把身份分成七类，遇到觉醒角色不够用了。
补四个正交维度，做成**独立的平行列表**，不要塞进身份编码：

| 维度 | 列表 | 取值 | 谁需要 |
|---|---|---|---|
| **技能可转移** | `资源表[玩家]` | 持有数 / 目标号 | 觉醒狼王（爪）、觉醒女巫（毒药次数/协助者）、觉醒隐狼（模仿） |
| **阵营可变** | `现阵营表[玩家]` | 1狼/2神/3民/4第三方 | 觉醒石像鬼转化者、觉醒孤独少女、觉醒隐狼模仿狼 |
| **跨阶段生效** | `守护到期(阶段,日)` | 阶段枚举 + 日号 | 觉醒守卫、觉醒白狼王诱导、觉醒骑士决斗 |
| **多人协商** | `协助者表 / 协助票箱 / 协助过表` | 玩家号 / 0-1 / 0-1 | 觉醒女巫 |

再加三个通用开关（几乎每个觉醒都要）：

```
技能封锁[p]      # 觉醒猎人夜死封技能、蚀日侍女吞噬、噩梦之影恐惧
翻牌豁免[p]      # 觉醒白狼王诱导狼人不翻牌、被魅惑替死
出局免疫层[p]    # 0 无 / 1 觉醒守护 / 2 秘密之身 / 3 替死 / 4 梦语者免疫夜伤
```

⚠️ **「出局免疫层」要有优先级**，同夜多层同时命中时：
```
觉醒守护(1) > 替死(3) > 秘密之身(2) > 守卫/解药/流光庇护 > 梦语者免疫夜伤(4)
```
且**同一层一晚只消耗一次**。不排序会出现「两个护盾都被扣掉、人还是死了」。

## §406 觉醒板子大全（一）：10 人场

> 板子仍然是**数据**（第三十三册 §320）：`名称 | 人数 | 身份串 | 开关`。
> 下表身份串直接可填进 `板子串表`。「狼」= 普狼 ×N。

| 板子 | 狼人阵营 | 神职 / 特殊 | 民 | 关键机制 |
|---|---|---|---|---|
| 觉醒之夜 | 2 狼 + **夜之贵族** | 预言家 / 女巫 / **觉醒愚者** | 4 | 夜仆；女巫**仅首夜可自救**；单爆吞警徽 |
| 寻香识命 | 2 狼 + **寻香魅影** | 守卫 / 女巫 / **觉醒预言家** | 4 | 集合查验；氤氲缠绕 |

## §408 觉醒板子的数据结构与开关

第三十三册 §334 的板子表有六个开关，觉醒板子要再加四个：

```
板子 = 名称 | 人数 | 身份串 | 原有六开关
       (有警长 / 屠边 / 明牌 / 双爆吞警徽 / 首夜遗言 / 自爆遗言)
     + 觉醒四开关
       ⑦ 女巫自救档   0=不可 / 1=仅首夜 / 2=全程
       ⑧ 有无民       0=有民 / 1=无民（屠民退化为屠城）
       ⑨ 转化允许     0=否 / 1=是（决定是否初始化 现阵营表 副本）
       ⑩ 诱导允许     0=否 / 1=是（月坠光渊专用，白狼王走诱导而非普通自爆）
```

「身份串」仍然用**逗号分隔的身份编码**，一个板子加角色只改这一行：

```
# 12 人月坠光渊：3 普狼 + 觉醒白狼王 + 预女猎 + 觉醒守卫 + 4 民
1,1,1,60,3,4,5,56,2,2,2,2        # 编码以工程 IDENTITIES 为准，见 §410
```

⚠️ **板子合法性校验**要加三条（第三十三册 §334 之外）：
1. `人数 = 身份串长度`（爱神局的人数+2 例外仍适用）。
2. 含**觉醒石像鬼**时，身份串里必须有**至少 1 个相邻非狼座位**可被转化 ——
   全狼板子会让技能空转。
3. `有无民 = 1` 时，胜负判定必须走「屠城」分支，
   且 `总民 = 0` 守卫不能被「存活民=0」误判（第三十三册 §344）。

## §410 与通用引擎的接口：状态位与死因码

### 死因码必须从 6 个扩到 15 个

第三十三册 §326 用 `死因 ∈ {1,2,4}` 判「猎人能不能开枪」。
觉醒体系引入大量新出局方式，继续复用旧码会串味：

```
1 狼刀      2 放逐      3 毒        4 枪        5 殉情      6 技能
7 自爆      8 被诱导自爆  9 被诱导连带 10 巡猎    11 决斗    12 梦语
13 狼王爪   14 替死      15 夜仆
```

配套规则：
- **觉醒猎人**的出局仍按 `死因 ∈ {1,2,4}` 判能否巡猎；
  `8 被诱导自爆` **不算**（它不是主动自爆，但也不是狼刀/放逐/枪）。
- `7 自爆` 才触发血月封印 / 双爆吞警徽计数；`8/9` 不触发。
- `12 梦语 / 14 替死 / 15 夜仆` 属于**技能结算**，跳过「免疫夜间伤害」层。
- `10 巡猎 / 11 决斗 / 13 狼王爪` 属于「带人」，要进**触发式死亡**那一层
  （第三十三册 §343 第四步），被带走者按自身死因继续结算。

### 新增全局状态位

```
现阵营表[玩家]      # 所有阵营查询一律读它，初始化自 阵营表[身份池]
资源表[玩家]        # 觉醒狼王爪等可转移资源
技能封锁[玩家]      # 夜死巡猎 / 吞噬 / 恐惧
```

## §412 十三个坑

1. **把觉醒当数值加强** → 规则全错。先读 §394 和 §404，确认被换掉的是哪个约束维度。
2. **给原型脚本加次数变量** → 觉醒守卫的「任何方式出局」、觉醒骑士的「双死」根本不是次数问题。
3. **`阵营表[身份]` 直接当现阵营用** → 转化者 / 变身者三套答案不一致。必须加 `现阵营表`。
4. **狼王爪写成「谁是狼王」单变量** → 亲传后两个能带人的狼必丢一个；用持有数表。
5. **模仿做成一步** → 觉醒隐狼当夜就能放毒；拆成身份 / 技能两阶段。
6. **梦语出局走夜间伤害通道** → 被自己的免疫挡掉，表现为「按了没反应」。
7. **秘密之身放在女巫之前** → 目标被救仍误消耗；必须在夜间结算最后。
8. **觉醒守护只免疫、不跳流程** → 被放逐者留下但白天多一轮发言，轮次算错。
9. **`被诱导自爆` 复用 `自爆` 死因** → 错误触发血月封印和双爆吞警徽。
10. **无民板子漏 `总民 > 0` 守卫** → 云端追踪 / 风声谍影 / 沙龙之夜开局直接判狼胜。
11. **「隔一晚」按白天计数** → 觉醒狼美人的挽歌幻象是**夜数差 ≥ 2**。
12. **结算与变身顺序反了** → 偶像出局那一帧先变身再判胜负，出现「刚变狼就赢」。
    与第三十五册红狼野孩子同源，**所有可变阵营角色通用**。
13. **板子编号 1-based 与数组下标 0-based 混淆**（本项目实踩）：Scratch `item k of 列表`
    取的是**第 k 项**，而 Python/JS 数组 `arr[k]` 是第 k+1 项。板子表首项是占位空串时，
    「脚本里的板子编号 = 数组下标 + 1」。曾把 `当前板子=28` 当成「月坠光渊12」，
    实际读到的是第 28 项（觉醒石像鬼12），且**张数恰好也是 12**，
    校验只查张数就查不出来 —— **板子装载必须断言具体身份编码，不能只断言张数**。
