# 题材速查卡（Genre Quick-Reference）

> 把 41 册手册（§1–§526）压成「做某题材先翻哪几节 + 必做 + 必避坑」。
> 完整内容看 `references/handbook-index.md` 对应段落；本卡只给「出活必需」的最小集。
> 复用范例：平台跳跃 `examples/platformer.yaml`（物理/手感）、打地鼠 `examples/whack_a_mole.yaml`（动作/计时）、接水果 `examples/fruit_basket.yaml`（计分/命）。

| 题材 | 必看 § | 必须有 | 高频坑（别踩） |
|---|---|---|---|
| **平台跳跃 / 横版** | §156–§166, §17 | 重力/地面/跳跃「一条规则一个循环」；脚下感应点地面检测；土狼时间 + 跳跃缓冲 | 跳跃只改坐标不存速度（应存 vy）；摩擦用减（铁律5 必须乘）；`rotationStyle` 用 `none` 而非 `left-right`（会整圈转） |
| **音游 / 节奏** | §433–§456, §46, **铁律27** | 单一 `songTime` + 公式重算（不 `y+=`）；判定窗口毫秒取帧长整数倍；先量化输入帧再取误差；Hold 判头尾；对象池预造角色 | 用 `wait` 累积节拍（误差叠加，应计时器）；判定窗口非帧长整数倍；长按只判头不判尾 |
| **射击 / 弹幕 / 摸金** | §116–§120, §479–§502, **铁律28/29** | 四层判定（射线→伤害→状态→目标）；30fps 线段扫掠防穿模；部位按高度分段；后坐力可复现表；摸金局外持久 | 子弹 <10px 穿目标（§33）；查表列表前导占位 0（错一位四层校验看不出）；无头环境用 `abs(dx)<R and abs(dy)<R` 测碰撞 |
| **MOBA / 塔防推塔 / 三国杀 / 自走棋** | §503–§526, §291–§304, **铁律19/24** | 一份骨架装多模式（差异压进装载表+优先级表+概率表）；波次用时钟公式不累加；补刀英雄绝对优先 + 距离 tie-break；回合角色**只在阶段回卷时推进**；判定/求桃/距离用查表；抽卡用 Park-Miller 整数迭代（`随机数` 积木不可复现） | 浮点用 `=` 判等（应带容差）；镀层把帧当秒；破塔奖励用 `破塔顺序=1` 当条件（反复发）；超级兵用破塔顺序判；三国杀每步都换角色；「全员无桃」提示写在 if 外覆盖救人提示；四模式共引擎互相污染变量 |
| **解谜 / 推箱子 / 迷宫** | §19, §22, §30, §51 | 地图存一条列表 `index=(y-1)*列+x`；推箱子看「右边第二格」；迷宫递归回溯 + 列表当栈 + 递归深度熔断；AABB 包围盒（碰撞盒比造型小一圈） | 用 `碰到` 像素级两两比对（慢且误判）；迷宫不节流绘制（卡） |
| **互动叙事 / 剧情** | §28, §34, §148–§155 | 分支对话用「状态 + 广播」；对话可跳过 + 锁操作；演出三段式（开始/进行/演出，`stop other scripts` 后广播回「进行」） | 长文本用 `say` 气泡（铁律2 改自制聊天框）；演出用亮度做淡入（亮度往白提不是黑，用虚像/全屏黑角色） |
| **桌游 / 卡牌 / 狼人杀** | §291–§304, §320–§348, §349–§372, §373–§393, §394–§412, §413–§432, **铁律22/24/25/26** | 板子是数据（名称│人数│身份串│开关）；位表第 k 项 = 编码 k（多写 0 整体错位）；警徽流三平行列表；死因码；红狼是游戏非身份 | 把「红狼」当身份做（实为游戏，女巫可自救等规则）；位表错位；两平级 IF 同帧覆盖；新月事件撤销按快照栈而非栈顶标记 |
| **模拟 / 经营 / 交通** | §1, §167–§176, §207–§221, §236–§248 | 大地图 + 小地图（相机变量 + 反向移动 + 置顶小圆点）；背景房间状态机（§C1）；ATO 分层控制 | 大地图直接整张渲染（应分块 + 小地图）；状态机不用广播而用 `switch backdrop`（§44 更可靠） |
| **联机** | §31, §127–§131 | 云变量每秒 ≤10 次、只存数字；**回合制最稳**；官方禁云聊天室 | 实时动作游戏用云变量（延迟炸）；把字符串塞云变量（只能存数字，须编码） |
| **UI / 菜单** | §197–§206, §5, §26, **铁律17** | 五层体积感（投影→外描边→渐变→顶高光→底内阴，序不可换）；窗口圆角 + 大窗；四态换造型不缩放；菜单用角色按钮（铁律10） | SVG 含 `text/filter/mask/clipPath/pattern/image`（铁律17 禁）；菜单用「询问」（铁律10 改按钮） |
| **声音设计** | §263–§276, **铁律18** | 四层响度（ui≈-18/fx≈-9/ev≈-3/amb≈-15 dBFS）；UI 音效 ≤0.25s 禁「播放直到结束」；首尾归零；BGM 直接挂 | 音效互打断（用克隆跑音效，§39）；`stop all sounds` 停不掉循环（须 `stop other scripts`） |
| **数学 / 推理** | §277–§290, **铁律19** | Python 基线 + 已知答案断言（8 皇后 92 / 质数 25）；化简 `round(分子/gcd)`；判等带容差；`log` 是 10 为底；回溯回退不 +1（否则 14 解） | 用 `=` 判浮点相等（应带容差）；`log` 当自然对数；回溯 +1 多算解 |

> 通用铁律全集见 `SKILL.md` 硬要求 + `references/hard-requirements.md`；
> 做某题材前，先在本卡找 §，再回 `handbook-index.md` 读对应段，最后套 `ir-patterns.md` 的骨架。
