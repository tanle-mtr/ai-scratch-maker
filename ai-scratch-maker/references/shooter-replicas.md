## §479 两条轴：射击对抗 vs 搜打撤

| | CS2 | 和平精英 | 三角洲·烽火地带 | 超自然行动组 |
|---|---|---|---|---|
| 品类 | 回合制战术 FPS | 大逃杀 BR | **PvPvE 搜打撤** | **PvE 合作恐怖摸金** |
| 人数 | 5v5 | ~100（含 AI） | 1~3 人小队 × 多队 | 1~4 人合作 |
| 胜负 | 先到 13 胜 / 炸弹 | 最后存活 | **带物资撤离** | **凑够金额并撤离** |
| 死亡代价 | 下回合重生、掉枪 | 本局出局 | **保险箱外全丢** | **携带物全丢** |
| 局外持久 | 只有回合内经济 | 无 | **仓库 / 哈夫币 / 交易行** | **职级 / 道具购买** |
| 时间压力 | 回合 1:55 + C4 40s | 缩圈 7~9 次 | 局内倒计时 + 撤离点 | **24 点前撤离**，越晚怪越强 |

**「摸金」= 搜打撤（extraction）的本质**，不是「打枪捡东西」这么简单：

```
局外仓库 → 选择带入装备（有成本）→ 进局
   → 搜刮（随机战利品）→ 遭遇 PvP/PvE（可能全丢）
   → 满足撤离条件并读条 → 撤离成功 → 带出物资入仓库 / 卖钱
   → 再买装备进局
```

⚠️ **复刻摸金必须做「局外持久状态」**。
只做一张图 + 撤离点，没有「带入成本 / 死亡全丢 / 仓库累积」，
玩家就没有「贪一个箱子还是立刻撤」的风险决策，整个品类塌掉。

⚠️ **CS 与和平精英没有局外仓库**：CS 的钱只在半场内累积，BR 每局清零。
把三种经济混成一个 `金币` 变量是最常见的架构错误。

## §480 统一抽象：命中 × 伤害 × 状态 × 局外

四款能共用一份引擎，把差异做成配置表：

```
模式      1 CS2 / 2 和平精英 / 3 三角洲摸金 / 4 超自然行动组
命中方式  hitscan / projectile（决定射线怎么算）
伤害表    武器 → 基础伤害 / 部位倍率 / 距离衰减 / 穿甲 / 射速
状态      血量 / 护甲值或等级 / 头盔 / 信号值 / 体力 / 负重
局内      回合时钟 / 圈阶段 / 撤离点 / 怪物强度时钟
局外      仓库（物品ID·数量·价值）/ 货币 / 职级
```

**四层判定顺序**（和音游「空间→时间→类型」同款思路）：

```
① 射线求交：这一发打到了谁、打在哪个部位、有没有穿墙
② 伤害管线：基础 → 部位 → 距离 → 护甲/穿甲 → 掩体衰减
③ 状态结算：扣血 / 扣甲 / 倒地 / 死亡 / 掉落
④ 局内目标推进：回合胜负 / 存活人数 / 撤离资格 / 目标金额
```

## §481 命中判定：hitscan / projectile / 扫掠

| | 代表 | 判定 | Scratch 实现 |
|---|---|---|---|
| **Hitscan** | CS 步枪/手枪/AWP | 开火瞬间沿视线做**一条射线**，无飞行时间 | 线段与玩家 AABB 求交，取最近 t |
| **Projectile** | 和平精英 / 三角洲远距离 | 子弹有速度、下坠、飞行时间 | 每帧推进弹丸 + **线段扫掠** |
| **投掷物** | 烟雾/闪光/雷 | 抛物线 + 碰撞/计时 | 重力积分 + 落地事件 |

```
# 射线 vs 轴对齐包围盒（slab 法）
对每个轴 a ∈ {x, y, z}:
    t1 = (min_a − origin_a) / dir_a
    t2 = (max_a − origin_a) / dir_a
    tmin = max(tmin, min(t1,t2));  tmax = min(tmax, max(t1,t2))
若 tmax ≥ max(tmin, 0) → 命中，距离 = tmin × |dir|
```

⚠️ **Scratch 30fps 下高速弹丸会「穿模」**：
每帧把子弹当点去检测，速度 900m/s 时一帧走 30m，直接越过人。
**必须做线段扫掠**：记录 `上一帧位置 → 本帧位置`，用这条线段与 AABB 求交，
而不是只测本帧的点。这一条不做，所有远距离对枪都是随机的。

⚠️ **命中部位不要用独立碰撞箱**：用求交点的 y 相对目标包围盒高度分段即可
（头 0.85~1.0 / 胸 0.5~0.85 / 腹 0.3~0.5 / 腿 0~0.3），
做四个角色碰撞箱会带来接缝处「打不中」的经典 bug。

⚠️ **掩体衰减**：射线先与墙体求交，若墙的 t 比玩家小 → 命中墙。
穿墙武器按材质给 `穿透系数`（木 0.7 / 薄铁 0.4 / 混凝土 0）。

## §482 伤害管线（四款通用，参数不同）

```
实际伤害 = 基础伤害
         × 部位倍率[部位]
         × 距离衰减(距离)
         × 护甲系数(护甲等级, 弹药穿透等级)
         × 掩体系数
         × (1 + 低信号值受伤加成)      # 仅和平精英
```

**CS2 风格**（护甲是数值 0~100，头盔单独）：
```
部位倍率: 头 4.0（有头盔约 1.0~2.5）/ 胸 1.0 / 腹 1.25 / 腿 0.75
护甲: 有甲时伤害 × ~0.5，同时扣护甲值；无甲全额
AK-47 对有头盔目标爆头 ≈ 111 原始伤害 → 一枪击杀
```

**和平精英 / 三角洲风格**（护甲是 1~N 级 + 弹药穿透等级）：
```
护甲等级 A ∈ 1..6，弹药穿透等级 P ∈ 1..6
P < A  → 只磨甲耐久，几乎不扣血（玩家俗称「刮痧」）
P = A  → 部分减免
P > A  → 全额甚至加成
```
⚠️ **这是三角洲最重要的数值规则**：低穿深弹打高甲「打中却打不动」是**设计**，不是 bug。
复刻时不要把穿透等级做成「加伤 buff」，要做成**能否击穿的门槛**。

**和平精英的信号值加成**（官方）：
```
信号值 75%~100% → 无额外受伤
低于 75% 后，每再降 25% → 受到的伤害上升一个台阶
信号值归零 / 圈外淘汰倒计时结束 → 直接淘汰（无视健康值）
```
⚠️ **信号值不是第二条血条**：它不掉血、不自动回复，
只放大受击伤害；回复只能靠**信号电池 / 全能医疗箱**。

**TTK**（Time To Kill）：`需弹数 = ceil(有效生命 / 单发实际伤害)`，
`TTK = (需弹数 − 1) × 60000 / 射速RPM`。平衡武器就调这三个数。

## §483 后坐力、散布、急停

```
后坐力图案[枪ID][第n发] = (垂直上抬, 水平偏移)   # 一张表，不是随机
散布(spread) = 基础散布
             + 连发累积(每发 +k，停火按指数衰减)
             + 移动速度 × 移动系数
             + 跳跃/空中 × 大系数
             − 蹲下 × 减免
             − 开镜(ADS) × 减免
实际弹道方向 = 视线方向 + 后坐力 + rand(−spread, +spread)
```

⚠️ **CS 的「急停」必须做成显式规则**：
松开方向键的瞬间仍有惯性，反向轻点（counter-strafe）才能立刻把散布清零。
写成 `速度=0 → 立即精准` 会让移动射击强得不真实。
CS2 还有 **subtick**：射击时间戳按鼠标点击的毫秒算，独立于帧/tick ——
Scratch 里对应「在按键事件里记 `输入时刻`，判定时不用当前帧时刻」。

⚠️ **后坐力图案用表不用随机**：玩家练压枪靠的是可复现的轨迹。
用 `随机数` 做水平抖动会让枪永远练不会。

⚠️ 与第三十八册 §435 同源：30fps 下射速 > 1800RPM 会多发放进同一帧，
要用「帧内按时间戳补发」而不是一帧一发。

## §484 CS2：MR12 回合状态机

```
阶段:  freeze(购买 15s) → live(1:55) → [炸弹已安放: 40s 倒计时] → roundEnd(结算)
胜利:  T 全灭 CT / C4 爆炸 / CT 拆弹 / CT 全灭 T / 时间到(CT 胜)
半场:  12 回合后换边，金钱重置 $800，连败档重置
赛点:  先到 13 胜（MR12）
```

**必须做成两级状态机**（阶段 × 子阶段），与第三十三册狼人杀同款：
```
阶段 0 冻结 / 1 进行中 / 2 炸弹已下 / 3 回合结束 / 4 半场 / 5 比赛结束
子阶段 购买 / 安放读条(3s) / 拆弹读条(10s，有拆弹器 5s) / 结算展示
```
⚠️ **C4 已下之后回合计时器要切换到 40 秒**，不能继续走 1:55。
这一个分支漏掉，炸弹局永远不会爆炸。

## §486 CS2 的 C4 与投掷物

| 物件 | 状态机 | 复刻要点 |
|---|---|---|
| **C4** | 携带 → 安放读条 3s → 倒计时 40s → 爆炸 / 被拆 | 下包者死亡后 C4 掉落可捡 |
| **拆弹** | 读条 10s（有钳 5s） | 读条中被打断要保留进度还是重置？按版本开关 |
| **烟雾弹** | 起爆 → 膨胀 → 持续 ~15~20s → 消散 | 遮挡视线（不做伤害），HE 可短暂炸开视野洞 |
| **闪光弹** | 引爆 → 视线夹角 × 距离 → 致盲时长 | 背对可减免；全队都会被闪（含自己） |
| **燃烧/莫洛托夫** | 落地 → 区域持续伤害 ~7s | 烟雾可灭火；区域按帧判定 |

⚠️ **投掷物是「区域 + 时间」效果，不是子弹**。
用一张 `区域效果表(中心, 半径, 类型, 起始, 到期)`，每帧对区域内实体结算一次，
别给每个火焰粒子建克隆（会撞 300 上限）。

## §487 和平精英：信号接收区状态机

```
圈阶段 k = 0..8（每局 7~9 次缩圈）
每阶段: 等待时长 / 收缩时长 / 目标中心 / 目标半径 / 圈外信号衰减速率 / 淘汰倒计时
状态:   等待 → 收缩中(半径线性插值) → 稳定 → 下一阶段
```

```
每帧:
    若 收缩中: 当前半径 = lerp(起始半径, 目标半径, 已过/收缩时长)
    距圈心 d = sqrt((px−cx)² + (pz−cz)²)
    若 d > 当前半径:
        信号值 -= 阶段衰减速率 × dt
        圈外倒计时 -= dt
        若 圈外倒计时 ≤ 0 → 立即淘汰（无视血量/信号值）
    否则: 圈外倒计时复位
```

⚠️ **官方规则三条**：
1. 圈内**信号值不减**，圈外缓慢减；**信号值不影响健康值，只放大受击伤害**。
2. 信号值**不自动回复**，只有信号电池 / 全能医疗箱能回。
3. 圈外**淘汰倒计时**逐次缩短（首圈约 180s、二圈约 140s，后期可到几十秒），
   结束直接淘汰。

⚠️ **衰减速率逐阶段递增**（前期约 0.4~1 点/秒，决赛圈可达数十点/秒），
后期圈外几乎站不住。做成 `阶段速率表`，别写成全局常量。

**「圈中圈」变体**：白圈内另有一个紫圈 = **下一圈预告**，
紫圈内同样扣信号值；收缩完成时紫圈变成新的白圈，再生成新紫圈。
复刻时就是「多存一份 `下一圈中心/半径` 并额外判一次区域」。

## §488 和平精英：跳伞、搜刮、空投、载具

```
开局: 航线（一条线段 + 高度）→ 玩家选点跳伞 → 自由落体/开伞 → 落地
搜刮: 建筑点位 → 容器 → 按战利品表抽取（§494）
空投: 定时 + 随机落点（偏向当前圈边缘）→ 高稀有度物资
载具: 位置 / 速度 / 油量；用于跑圈
决赛圈: 存活人数 → 加速缩圈；最后 1 人/队获胜
```

⚠️ **100 人同图在 Scratch 里做不到**（联机云变量上限 + 300 克隆上限）。
复刻要做**缩规模房间 + AI 机器人**：
- 真人 4~8，其余用「虚拟玩家」只存 `(位置, 血量, 状态)` 一张表，不建角色；
- 只在玩家视野/交战范围内实例化为角色（对象池）。
这正好复用第二十二册「对象池 GC 对账」和第十四册的联机同步。

⚠️ **落地搜刮的物资要按点位稀有度分区**（热门点高风险高收益），
否则所有房子一样，跳伞决策就没意义了。

## §489 摸金通用循环：搜打撤

**五阶段状态机**（三角洲与超自然行动组共用，参数不同）：

```
0 局外准备   选带入装备 / 买道具 → 扣仓库与货币
1 进局       生成地图 / 容器 / 撤离点 / AI 或敌队
2 搜刮       开容器 → 权重抽物 → 放入背包 → 更新负重与目标金额
3 遭遇       PvP / 怪物 AI；死亡 → 掉落全部（保险箱/安全箱除外）
4 撤离       满足撤离条件 → 读条 → 成功/被打断
5 结算       带出物入仓库 → 卖钱 / 升职级 → 回到 0
```

⚠️ **「撤离 > 物资 > 击杀」要写进 AI 与 UI**：
击杀本身不加分，只有带出去的东西算收益。
复刻时若给击杀发奖励，玩家会去刚枪，品类就变成普通 FPS。

⚠️ **死亡掉落必须有「安全箱例外」**：
三角洲的 3×3 安全箱在阵亡时保留，
这是「拿到金条先塞安全箱」这条核心决策的来源。
超自然行动组则是「死亡携带物全丢，队友可搬尸体 / 除颤仪复活」。

## §490 三角洲·烽火地带：护甲 × 弹药穿透

```
护甲等级 A ∈ 1..6（头/甲分开），弹药穿透 P ∈ 1..6
P < A → 伤害大幅衰减，主要扣甲耐久
P ≥ A → 正常/全额伤害
```

⚠️ 「没 3 级弹不打甲」是玩家共识，说明**穿透是门槛不是加成**。
实现：
```
若 P < A:  实际伤害 = 基础 × 0.15 ;  甲耐久 -= 基础 × 0.8
若 P = A:  实际伤害 = 基础 × 0.75 ; 甲耐久 -= 基础 × 0.5
若 P > A:  实际伤害 = 基础 × 1.0  ; 甲耐久 -= 基础 × 0.2
```

**物资品质**：白 < 绿 < 蓝 < 紫 < 金 < 红（价值与权重见 §494）。
**难度档**：普通 / 机密 / 绝密 → 影响 AI 强度、敌队装备、战利品权重。
**干员技能**（蜂医治疗烟 / 威龙位移等）：做成「技能资源 + 冷却」两变量，别写进状态机。
**声音感知**：静步 / 跑步 / 翻窗 / 切枪产生不同半径的「声波事件」，
附近玩家与 AI 按半径感知 —— 这是一张事件表，不是距离判定写在角色里。

## §491 三角洲：撤离点类型与曼德尔砖

| 撤离类型 | 条件 | 复刻要点 |
|---|---|---|
| **固定撤离**（绿标） | 到点 + 读条 | 常被蹲守 |
| **随机/概率开启**（白标） | 局内随机开放 | 要存 `是否开放` |
| **付费撤离** | 消耗局内货币/物资 | 扣费后才允许读条 |
| **条件撤离** | 拉杆 / 通电 / 直升机 / 快艇 | 先完成前置事件 |
| **特殊载具撤离** | 限人数 / 限时 | 名额表 |

```
撤离结算:
    若 玩家在撤离区 且 撤离点开放 且 前置条件满足 且 未被打断:
        读条 += dt
        若 读条 ≥ 需读秒: 撤离成功 → 结算带出物
    否则: 读条归零（或保留，按版本开关）
```
⚠️ **到达 ≠ 能走**。条件不满足时不要让玩家白跑半张图，UI 要提前显示条件。
⚠️ **读条期间受击应打断**（这是撤离点博弈的核心）。

**曼德尔砖**：高价值可破译物，
```
破译 → 价值大幅提升 + 向全场广播携带者位置
```
⚠️ 它是**风险放大器**：拿到之后怪物/敌队压力上升，必须尽快撤。
复刻时用 `全局标记 = 携带者编号`，AI 与敌队的搜索目标改为该玩家。

**安全箱**：3×3 格子，死亡不丢；背包其余全丢。
**负重**：背包价值/重量超速 → 移速下降（影响撤离路线选择）。

## §492 超自然行动组：目标金额 + 时钟 + 动态难度

```
局内时钟: 从开局到 24:00（游戏内时间），实际按分钟压缩
目标金额: 浅层 10,000 / 深层 25,000
撤离条件: 累计「已放入公司车收纳柜」的价值 ≥ 目标金额 → 可乘车撤离
失败: 超时 / 全员死亡 → 携带物全失
```

⚠️ **必须是「放回车的收纳柜」才计数**，不是捡到身上就算。
这条决定了「两人搜、一人运输、一人殿后」的团队分工，
也产生了「身上带一堆值钱东西但没运回去就死了」的张力。

**动态难度**（本作最独特的机制）：
```
危险指数 D = f(局内时间, 是否拿到龙珠, 当前价值)
  · 时间越晚，怪物刷新频率与强度越高
  · 浅层 12:00 前拿龙珠 / 深层 16:00 前（资料值，按版本调）
  · 拿到龙珠 → D 跃升，怪物潮增强
  · 16:00 后车附近怪物集中（撤离变难）
```
⚠️ 做成**一条时钟曲线**（`D = 基础 + 时间系数×分钟 + 龙珠标志×跃升`），
别用「每 N 秒随机刷一只」，那做不出「越拖越危险」的压迫感。

**体力 / 负重**：物品越多移速越慢，超重加速体力消耗；血量低于 20 减速。
**角色技能**：侦查（45m 扫描宝物/棺椁）、治疗（复活 / 急救翻倍）、
战斗（20s 狂暴）、盗墓贼（免疫机关 / 快开棺）、道具师（延长道具效果）。
统一做成 `技能ID / 冷却 / 持续时间 / 资源` 四字段，不写死在每个角色脚本里。

## §493 超自然行动组：怪物 AI 与环境互动

**通用怪物状态机**（巡逻 → 感知 → 追击 → 攻击 → 失去目标）：
```
感知 = (距离 < 视距 且 在视锥内 且 无遮挡)
     OR (距离 < 听距 且 玩家发出声波事件)
追击 = 朝目标移动；丢失目标 N 秒 → 回巡逻
```

| 怪物 | 特性 | 破解方式（复刻成规则分支） |
|---|---|---|
| 影怪（乌鸦哥） | 背后偷袭、拖拽 | 站同高度平台 / 葫芦收服 |
| 鬼新娘 | 唢呐声、锁定玩家 | 站高处击杀 / 电磁枪吸附 |
| 精绝女王 | 瞬移、直视危险 | 贴墙卡位 / 关门 / 符咒 |
| 假人 | **伪装成队友** | 看是否持物、双手姿态；击杀后解救被寄生队友 |
| 鼓狮 | 变身时高速 | 站二级高度（路灯）蹲攻 |
| 盲犬 | 只听声 | 蹲下静步脱离 |
| 史莱姆 | 音乐削弱 | 音响播放 |

⚠️ **「关门隔离」是显式规则**：约 95% 怪物受门限制。
门必须是一个**可开关的通行阻挡**，不能只是装饰。
⚠️ **高低差是有效防御**：玩家站在高台时近战怪打不到 ——
要存 `玩家高度层` 与 `怪物可攻击高度差` 两个字段。
⚠️ **假门**：攻击后听是否有怪物叫声判断真假 —— 一个「攻击门 → 触发表」的小机关。

**三阵营推理模式**（10 人场：6 员工 / 2 伪人 / 2 中立）：
员工做任务或投票放逐伪人、伪人袭击/破坏、中立达成专属目标。
这直接复用第三十三册 `werewolf-complete.md` 的**板子表 + 夜间/投票状态机**，
只需把「身份」换成「阵营 + 专属任务」，**不要重写一套推理引擎**。

## §494 战利品表、背包格子、负重

**权重抽取**（所有搜刮类通用）：
```
战利品表[容器类型] = [ (物品ID, 权重, 品质, 价值, 占格), ... ]
抽取:
    总权重 = Σ 权重 × 稀有度系数[难度]
    r = random(0, 总权重)
    累加直到 ≥ r → 命中该条
```
⚠️ **难度改的是权重，不是掉落集合**。
做成三张表（普通/机密/绝密）会让加物品时要改三处，必漏。

**品质**：白 < 绿 < 蓝 < 紫 < 金 < 红；超自然行动组用紫/金（面具约 20 万、金鸟 4 万）。
**背包**：两种模型二选一，别混：
- **格子制**（三角洲 3×3 安全箱 / 俄罗斯方块）：物品有 `宽×高`，要写装箱算法；
- **重量制**（超自然行动组）：物品有重量，总和决定移速。

**负重 → 移速**：
```
移速 = 基础移速 × clamp(1 − 负重/上限 × 0.5, 0.4, 1)
```
⚠️ 负重影响的是**撤离能不能跑得掉**，不是纯数值装饰。

## §495 局外经济：仓库、货币、保险、职级

| 游戏 | 局外状态 |  death 后 |
|---|---|---|
| CS2 | 只有半场内金钱，半场重置 | 掉枪，下回合重生 |
| 和平精英 | 无（每局清零） | 本局出局 |
| 三角洲 | **仓库 + 哈夫币 + 交易行** | 保险箱外全丢 |
| 超自然 | **职级 + 道具购买** | 携带物全丢，可复活 |

```
仓库表: 物品ID / 数量 / 单价 / 来源局
结算(撤离成功): for 带出物: 仓库[ID] += 数量
死亡: 背包清空；保险箱物品保留；带入装备丢失（除非有保险）
```

⚠️ **「带入装备」也要记账**：进局时从仓库扣除，死亡就没了。
不复刻这一步，玩家可以无限白嫖顶级装备，风险决策消失。
⚠️ **交易行价格随时间波动**（玩家在线高峰更贵）属于可选深度，
做成 `价格 = 基准 × 时段系数` 一张表即可。

## §498 射线数学与 Scratch 能力边界

```
# 2D 俯视简化（推荐给 Scratch 复刻）
射线: P(t) = O + D·t，t ∈ [0, maxDist]
圆目标: |P − C|² ≤ r²  → 解一元二次，取最小正根
矩形目标: slab 法（§481）
墙体: 先与墙线段求交，取最小 t 与玩家 t 比较

# 3D/伪3D（第一人称）
用第十六册 DDA 栅格射线 或 第十五册透视除法；
命中部位按交点 y 在目标包围盒内的相对高度分段。
```

⚠️ **Scratch 没有 `atan2`**（第三十册）：方向由角度直接给，别反算。
⚠️ **三角函数吃角度不用弧度**。
⚠️ **没有原生 3D**：真 3D 用画笔光线投射（已有多册范式），
或做**俯视 2D 射线**——对 CS/摸金的核心判定完全够用，且能省下大量复杂度。
⚠️ **联机**：云变量只能传少量数值（第十四册），
同步「位置 + 朝向 + 开火事件」即可，不要试图同步整个背包。
⚠️ **100 人 / 大量怪物**：虚拟实体表 + 视野内对象池，别建 100 个角色。
⚠️ **30fps**：所有快速移动必须做线段扫掠（§481）；
爆炸/烟雾/圈伤害按 dt 结算，别按帧数。

## §500 校验清单（24 条）

**射击通用**
1. hitscan 取最近命中；墙的 t 更小则命中墙。
2. 高速弹丸用**上一帧到本帧的线段扫掠**，跨过薄目标不漏判。
3. 部位倍率按交点高度分段，接缝处不出现「打不中」。
4. 伤害顺序：基础 → 部位 → 距离 → 护甲/穿透 → 掩体。
5. 后坐力图案可复现（同枪同发数同偏移）；散布随移动/连发/跳跃增加、蹲下与开镜减少。
6. 急停前有散布惯性；射击用输入时刻而非当前帧时刻。

**CS2**
7. MR12：12 回合换边、$800 重置、先到 13 胜。
8. 胜/负/炸弹/拆弹四种奖励金额正确；连败阶梯 +$500、5+ 封顶 $3400。
9. 赢一回合连败档**降一级**（可切版本为清零）。
10. 击杀奖励按武器类别（刀 1500 / 霰弹 900 / SMG 600 / AWP 100）。
11. C4 安放后计时切到 40s；拆弹 10s / 有钳 5s；读条可打断。
12. 投掷物按「区域 × 时间」结算，不按粒子。

**和平精英**
13. 圈阶段表逐阶段推进（等待→收缩→稳定），半径线性插值。
14. 圈内信号值不减；圈外按阶段速率递减，速率逐阶段递增。
15. **信号值不掉血**，只放大受击伤害（<75% 每降 25% 上一阶）。
16. 信号值只能用电池/医疗箱回复；圈外淘汰倒计时结束直接淘汰。
17. 交付前虚拟玩家不超对象池容量；超视野实体不实例化。

**摸金**
18. 进局扣带入装备、撤离入仓库、死亡清空背包（**保险箱/安全箱保留**）。
19. 穿透等级 **< 护甲等级**时只磨甲不掉血；`>` 时全额。
20. 撤离需「在区内 + 点开放 + 前置条件 + 读条完成」，受击打断。
21. 曼德尔砖/龙珠触发全局暴露 / 危险指数跃升。
22. 战利品按权重抽取，难度只改权重；负重影响移速。
23. 超自然：**放回收纳柜才计入目标金额**；浅层 10000 / 深层 25000；超时或全灭失败。
24. 怪物 AI 有巡逻/感知/追击/丢失目标；**关门隔离**与**高低差防御**生效；假人伪装可辨。

## §501 十七个坑

1. **把摸金做成「打枪捡东西」** → 没有带入成本与死亡全丢，风险决策消失。
2. **CS / BR 也加仓库** → 三种经济混成一个金币变量，半场重置全乱。
3. **和平精英把信号值当第二血条** → 官方：信号值不掉血，只放大受击伤害。
4. **信号值自动回复** → 必须靠电池/医疗箱，否则跑圈无成本。
5. **圈外只扣血不设淘汰倒计时** → 后期可以硬抗毒圈苟到决赛。
6. **C4 下包后仍走 1:55** → 炸弹永远不会爆。
7. **连败奖励赢一回合直接清零** → CS2 是降一级，ECO 节奏全变。
8. **击杀奖励统一 $300** → SMG/霰弹的经济价值消失，ECO 局没有反打手段。
9. **穿透等级做成「加伤 buff」** → 低穿弹也能磨死六级甲，三角洲数值崩坏。
10. **撤离点到了就能走** → 条件/付费/拉杆/读条全丢，撤离点伏击博弈消失。
11. **撤离读条不可打断** → 最精彩的「最后三秒被拉下来」没了。
12. **死亡后带入装备还在仓库** → 无限白嫖，摸金经济崩溃。
13. **子弹按帧点检测** → 30fps 下高速弹穿模，远距离对枪随机。
14. **用四个碰撞箱做部位** → 接缝处打不中；应按交点高度分段。
15. **后坐力用随机数** → 压枪练不会，手感永久「飘」。
16. **超自然把「捡到」当「完成」** → 没有运输分工，也没有「身上带一堆却没运回去」的张力；
    另外别漏「关门隔离 95% 怪物」和高度差，否则怪物无解。
17. **查表列表多写前导占位 `0`**（本项目实踩两次：身份位表 / 本册伤害表）→
    `item_of_list` 是 **1-based、直接读 `arr[index-1]`**，不需要占位。
    多写一个 0 会让部位倍率、连败阶梯、击杀奖励、圈衰减**全部整体错一位**，
    且症状很迷惑（爆头变 1×、首圈不扣信号值），四层校验完全看不出来，
    **只有行为断言能抓**。新增查表列表一律从「第 1 项就是编码 1」开始。

> 收尾一句：**射击部分只有一条伤害管线，摸金部分只有一个闭环**。
> 把「命中→伤害→状态」和「带入→搜刮→撤离→入账」这两条做对，
> 四款作品剩下的都是配置表。

- **CS2**：2026 年 MR12 经济资料（SkinPulse / csdb.gg / Counter-Strike Wiki / 赛事分析）给出的
  回合奖励、连败阶梯、击杀奖励、武器价格。⚠️ **「赢一回合后连败档是清零还是降一级」各资料有冲突**，
  本册按「降一级」实现并做成开关。subtick 命中注册、武器伤害阈值（AK 爆头 111）来自赛事分析文章，
  属社区实测，按目标版本调整。
- **和平精英**：**官方 gp.qq.com 攻略**（信号接收区三条规则、信号值 75% 阈值、
  每降 25% 伤害上一阶、不自动回复、圈外淘汰倒计时 180s→140s 递减、
  「圈中圈」紫圈预告下一圈）为最可靠来源。
  具体缩圈时间表与每秒衰减值来自第三方整理（多个版本互相矛盾），
  **本册只给「阶段表」结构，数值必须做成可配置**。
- **三角洲行动·烽火地带**：玩家攻略站与社区整理（搜打撤循环、白<绿<蓝<紫<金<红、

  ⚠️ 无官方公开数值表，穿透/伤害系数是**机制模型**，需按实机调参。
- **超自然行动组**：多家游戏资料站（浅层 10000 / 深层 25000、24 点撤离、收纳柜计数、
  龙珠触发危险跃升、动态难度、体力负重、角色技能、14 种怪物与破解方式、
  关门隔离 95%、员工-伪人-中立 10 人推理场）。⚠️ 版本更新快、数值可能变动，
  目标金额与时间节点做成配置；三阵营模式直接复用第三十三册狼人杀引擎。
- **通用**：hitscan / 弹道扫掠 / slab 求交 / 对象池 / 云变量联机限制见本 skill 第十二、
  十四、十五、十六、二十二、三十册；Scratch 30fps 与 300 克隆上限见铁律 12 与第三十八册 §435。
