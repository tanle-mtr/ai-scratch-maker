# 红狼（狼人杀经典版）完全手册（第三十五册，§373–§393）

> **先纠正一个常见误解：「红狼」不是身份，是一款游戏。**
>
> 「红狼」是玩家对**假面科技 2016 年 12 月推出的《狼人杀》**的俗称（因红色 logo），
> 正式别名还有「狼人杀经典版」「经典狼人杀」「口袋狼人杀」。它是国内第一款线上狼人杀 App，
> 奠定了后来所有狼人杀 App 的基本玩法与操作模式，累计用户超过 2 亿。
>
> **它和网易《狼人杀-官方正版》是两款不同的游戏**：角色体系不同、板子不同、
> 部分规则甚至相反（最典型：**红狼的女巫可以自救，网易的不行**）。
> 所以第三十三册（网易体系）与本册**不能混用** —— 写之前先确认用户要哪一款。

---

## §373 两款狼人杀的定位与三大硬差异

| 维度 | 红狼（经典版 / 口袋狼人杀） | 网易（狼人杀-官方正版） |
|---|---|---|
| 上线 | 2016.12（国内第一款） | 2017 年代理发行 |
| 角色数 | **30+ 专属角色** | 60+（含觉醒系） |
| 板子 | **15 个官方板型**，多为「1 神 + 1 狼」的机制对子 | 40+，多为「4 神 4 民 4 狼」竞技场 |
| 人数 | **6~12 人**（基础板有 6/7/8/9/10/11/12 七档） | 6~18 人 |
| 画风 | 平面卡通、红色 logo | 哥特写实 |
| 胜负 | **屠边**（神全灭 或 民全灭） | 屠边（主流）/ 屠城（少数） |

### 三条必须记住的规则差异

**① 女巫可以自救。**
红狼：女巫「可对自己用药」。
网易：女巫**不可自救**。
→ 同一段代码在两边跑，红狼那边女巫永远救不了自己，玩家第一局就会发现。

**② 首夜平安夜会「吃掉」后续所有夜间遗言。**
红狼：「夜晚死亡玩家仅首夜有遗言，**若首夜平安夜则此后夜晚死亡玩家也无遗言**」。
网易：只按「是否首夜」判，不看首夜是否平安。
→ 红狼这条是**状态记忆**：需要记住「首夜有没有死人」，而不是只记「现在第几夜」。

**③ 遗言只看死亡时间，不看死因。**
红狼：毒杀、枪杀、殉情、狼杀、放逐**遗言机会完全相同**；
并且「猎人枪杀、白狼王带人的目标」视为**与发动技能者同一时间死亡**；
「女巫毒杀目标」视为**夜晚死亡**。
网易：也是按时间，但**白狼王带走的人没有遗言**（红狼明确写「被白狼王带走的除外」——
注意：这一条例外与「只看时间」并列，说明红狼对白狼王带人**也不给遗言**）。

> 这三条是本册存在的理由。**如果只抄第三十三册的规则表去写红狼，必错。**

## §374 身份总表：30+ 角色按阵营分四块

红狼的角色分四个阵营，但**胜利条件只按「好人 / 狼人 / 第三方」三套算**：

| 阵营 | 角色数 | 胜利条件 |
|---|---|---|
| **平民阵营**（好人） | 5 | 放逐所有狼人阵营 |
| **神职阵营**（好人） | 20+ | 放逐所有狼人阵营 |
| **狼人阵营** | 14 | **杀死所有平民 或 所有神职**（屠边） |
| **第三方阵营** | 4 | 各自独立（§382） |
| **附加身份** | 1（警长） | 不分阵营，1.5 票 |

**关键结构**：平民和神职**分开计胜负**，所以「屠边」在这里是
「**杀光平民** 或 **杀光神职**」—— 这和网易一样，但红狼的板子里**平民和神职的数量比很悬殊**
（例如疯狂动物园是 3 民 + 3 神 + 3 狼，机械狼是 4 民 + 4 神 + 4 狼），
狼人的策略选择完全不同。

## §375 平民阵营（5 个）

| 身份 | 技能 | 实现要点 |
|---|---|---|
| **村民** | 无任何技能 | 标准填充位 |
| **小绵羊** | 无技能（疯狂动物园的「村民」） | 与村民同实现，只换名字与造型 |
| **老酒鬼** | ① **不会被狼美人诱惑**；② 被女巫毒 / 被猎人开枪**延迟一天生效**（第二天同一时刻吃技能，并在**发言结束后、投票之前**死亡） | **两段式死亡**：先标记「待死」，跨一个白天再真正结算 |
| **大公鸡** | 夜里被狼人杀死 → **第二天无法叫醒大家，跳过一个白天，直接进入黑夜** | 死人不只影响「谁出局」，还会**改变流程**（少一个白天） |
| **厚皮狼** | 夜里**被猎人击杀时要多杀一次**才能死（被毒、被投票、白天被猎人开枪除外） | 「多命」机制：一个 `剩余命数` 计数器，只对「夜间猎人击杀」扣 |

### 老酒鬼的「延迟死亡」怎么实现

这是红狼最有代表性的机制，也是最容易写成「当场死」的：

```
死亡事件(老酒鬼, 死因=毒 或 枪):
    标记 待死[老酒鬼] = 1
    标记 待死回合[老酒鬼] = 当前回合 + 1
    // 不加入「今晚死亡名单」，不当场公布

每个白天「发言结束、投票开始前」:
    对每个 待死=1 且 待死回合=当前回合 的玩家:
        真正死亡(该玩家)        ← 此时才进死亡名单、才公布
```

⚠️ **必须卡在「发言结束、投票之前」**：如果放在投票之后，
被延迟的人还能投票，而规则里他这一票不该算。

### 厚皮狼的「多命」怎么实现

```
夜间猎人击杀(目标):
    若 目标 = 厚皮狼 且 剩余命数[目标] > 1:
        剩余命数[目标] -= 1
        返回 "未死亡"            ← 关键：目标不进死亡名单
    否则:
        加入 今晚死亡
```

⚠️ **只对「夜间猎人击杀」生效**：被毒、被投票、白天被猎人开枪都**一次死**。
把条件写成「被猎人击杀」而不区分昼夜，厚皮狼会变成打不死的怪物。

## §376 神职·基础五神（与网易的差异点）

| 身份 | 技能 | 与网易的差异 |
|---|---|---|
| **预言家** | 每晚查验一人：狼人 / 好人 | 无差异 |
| **女巫** | 解药 + 毒药，同一夜只能用一瓶 | ⚠️ **可以对自己用药**（网易不可自救） |
| **猎人** | 死亡时可开枪；死于女巫毒药 或 **被白狼王自爆带走** 时不能开枪 | 红狼明确写了「白狼王自爆带走」这一条 |
| **守卫** | 每晚守一人（**含自己**），不能连续两晚守同一人 | 红狼明确「含自己」（网易通常也含，但没写在主规则里） |
| **白痴** | 白天被投票出局可翻牌免死，此后**失去投票权、保留发言权**；狼人须夜间杀死他 | 无差异 |

**女巫可自救的连带影响**：

- 女巫第一晚被刀 → 可以救自己 → **首夜不会出现「女巫被刀」的崩盘局**
- 因此红狼的板子里，狼人**首夜刀女巫的收益远低于网易**
- AI 狼人策略要跟着改：**红狼优先刀预言家/关键神，网易优先刀女巫**

⚠️ 如果只改一行 `可自救 = 1` 而不改 AI，会写出「狼人一直刀女巫、一直无效」的呆 AI。

## §377 神职·信息类（6 个）

| 身份 | 技能 | 实现要点 |
|---|---|---|
| **通灵师** | 每晚查验一名玩家的**具体身份** | ⚠️ 查机械狼时显示**其学习之后的身份** —— 要先算「已学」再返回 |
| **守夜人** | 每晚得知**上一个白天被放逐者**的**具体身份**（比守墓人更细：守墓人只知好坏） | 只回放「上一个白天」，不要累计 |
| **熊** | 天亮时若**左右相邻存活者**中有狼 → 宣布「熊咆哮了」；否则「熊没有咆哮」 | ⚠️ **熊死亡 或 被冰冻（企鹅）→ 无法咆哮**；相邻玩家死亡则**顺延至左右存活玩家** |
| **洞悉长老** | 持「洞悉之眼」；**每晚必须把眼移交给另一名玩家**；**收到眼的狼人会死亡**，同时眼消失 | 传递链 + 狼人检测 + 眼销毁，三个状态 |
| **巡警** | 首任警长出现当晚，巡警用手势告诉法官**是否信任警长**；随后警长选一人查验 —— **被信任则告知具体身份，否则不告知结果** | 与警长系统**强耦合**：必须先有警长 |
| **禁言长老** | 每晚选一人，令其下个白天**不能说话**；不能连续两晚同一人 | 禁言是「禁止发言」不是「禁止投票」 |

### 熊的判定顺序（最容易写错）

```
天亮宣布顺序（疯狂动物园板子）：
  ① 宣布大公鸡存活信息（是否跳过一个白天）
  ② 宣布熊咆哮信息
  ③ 宣布昨夜死亡信息
  ④ 发言 → 投票
```

⚠️ **熊的信息在死讯之前宣布**。如果把熊放在死讯之后，
「熊昨晚被刀了」这件事会先被公布，咆哮就失去意义（死人不会咆哮，本来就该静音）。

### 洞悉之眼的完整状态机

```
眼持有者 = X
夜间「洞悉长老」行动:
    若 眼已销毁 → 跳过
    选择 接收者 Y（不能是自己）
    若 身份[Y] ∈ 狼人阵营:
        死亡(Y)                  ← 狼人碰眼即死
        眼销毁 = 1
    否则:
        眼持有者 = Y
```

⚠️ **三件事都要做**：判狼、判死、销毁眼。只判死忘了销毁，眼会一直传下去，
每夜稳定杀一狼 —— 好人直接无敌。

## §378 神职·保护与干扰（7 个）

| 身份 | 技能 | 硬约束 |
|---|---|---|
| **织梦人** | 每晚选一人成为**梦游者**（不知情，**免疫夜间伤害**） | **织梦人夜间死亡 → 梦游者一并死**；**同一人连续两晚被梦游也死** |
| **企鹅** | 夜里**被猎人击杀要多杀一次**（被毒/投票/白天枪除外）；另可**冰冻**一名玩家（疯狂动物园） | 冰冻 = 让熊无法咆哮；属「多命 + 控制」双技能 |
| **小女孩** | 每晚狼人行动时可**睁眼偷看**；**被狼人发现立即死亡，且当晚狼人无法杀人**；**不能被守护**，可被女巫救活，**有遗言** | 三个例外同时成立才是对的：不可守 / 可救 / 有遗言 |
| **月夜祭司** | **夜间被狼人杀死 → 次日晚上狼人失去杀人能力** | 死后的**下一晚**生效（不是当晚） |
| **鸦语者** | 每晚诅咒一人，该人**下一个白天放逐投票额外 +1 票**；不能连续两晚同一人 | 与网易「乌鸦」同技能 |
| **猎魔人** | 第 2 晚起每晚狩猎一人：对方是狼 → **次日**对方出局；对方好人 → **次日**猎魔人出局 | **女巫毒药对猎魔人无效** |
| **炸弹师** | 白天投票阶段**被投出局 → 所有投票给炸弹师的玩家全部出局，且不能发动技能** | 一次一换多；⚠️「不能发动技能」意味着猎人/狼王也不能开枪 |

### 小女孩的判定链

```
狼人行动阶段:
    若 小女孩 睁眼:
        若 随机/规则判定被狼人发现:
            死亡(小女孩)                 ← 立即
            今晚狼刀无效 = 1              ← 关键：整晚狼人不能杀人
        否则:
            小女孩获得「狼人名单」         ← 偷看成功
```

⚠️ **「被狼人发现」必须有一个明确判定**（建议：狼人当晚选择「查看小女孩」即视为发现），
否则这条规则无法实现。红狼原文没写判定方式，属于房规空间 —— **实现时必须自己定一条并写进规则说明**。

## §379 神职·特殊机制（6 个）

| 身份 | 技能 | 实现要点 |
|---|---|---|
| **变脸师** | 开局法官选**三张有特殊能力的角色牌**置于桌中央；每晚开始时变脸师**选其中一张并获得其能力一回合**，**次日晚上开始前该卡移出游戏** | 三张牌是「一次性消耗品」；获得能力要**临时挂载**，用完卸掉 |
| **牧羊人** | 拥有一头牧羊犬；**牧羊人被狼人杀害时，距离最近的狼人被咬死**；**若最近的狼人有两名，技能发动失败** | 「距离」要定义（座位环距）；并列时**失败**不是随机 |
| **招魂师** | 每局限一次，夜晚召唤**上一个白天死亡**的玩家以**幽魂形态**继续：不受伤害、夜晚闭眼、失去所有技能、**可发言与投票**、**计算胜利条件时视为已死亡** | 「算死亡」与「能投票」并存 —— 胜负判定必须走 `真实存活`，投票走 `可投票` |
| **骑士** | 白天投票前亮身份决斗一人：目标狼人 → 狼死并进黑夜；目标好人 → 骑士死并继续流程；**每局一次** | 与网易一致 |
| **老酒鬼** | 见 §375 | 平民阵营但属「抗性」类 |
| **爱神（丘比特）** | 开局指定两人（**可含自己**）成为情侣；一人死另一人殉情 | 见 §382 第三方判定 |

### 牧羊犬的「距离」定义

```
距离(A, B) = min(|A − B|, 人数 − |A − B|)     ← 环形距离
最近狼 = 所有存活狼人中 距离(牧羊人, 狼) 最小的那些
若 数量(最近狼) = 1 → 咬死它
若 数量(最近狼) ≥ 2 → 技能失败（不咬）
```

⚠️ **并列时「失败」而不是「随机选一个」**：这条是红狼的设计意图
（牧羊犬会犹豫），改成随机会让技能强度翻倍。

### 招魂师的「两个存活」必须分开

```
真实存活[玩家]   = 0/1     ← 胜负判定只看这个
可投票[玩家]     = 0/1     ← 幽魂 = 1
可发言[玩家]     = 0/1     ← 幽魂 = 1
可被技能选中[玩家] = 0/1    ← 幽魂 = 0（不受伤害、不吃技能）
```

⚠️ 用一个 `存活` 变量同时表达这四件事，招魂师一定写错：
要么幽魂不能投票（失去意义），要么幽魂算存活（狼人永远屠不了边）。

## §380 狼人·基础（5 个）

| 身份 | 技能 | 硬约束 |
|---|---|---|
| **狼人** | 每晚共同袭击一人 | — |
| **白狼王** | 白天**自爆并带走一人**，然后进入黑夜 | ⚠️ **不可在投票环节和遗言环节自爆**（网易允许白天任意时刻） |
| **狼美人** | 每晚参与袭击后可**单独睁眼魅惑一人**；**狼美人死亡时，当晚被魅惑者殉情**；**不能自爆、不能自刀**；不能连续两晚同一人 | 殉情范围是「**当晚**被魅惑者」 |
| **黑狼王** | 与狼人共同袭击；**死亡时可带走一人**；**死于女巫毒药时不能带人** | 与网易「狼王」同技能 |
| **暴狼** | 与狼人共同袭击；**白天发言时可自爆**进入黑夜 | ⚠️ 同样**投票和遗言阶段除外** |

### 白狼王「三个不能自爆的时点」

```
可自爆 = 1
        且 当前阶段 ≠ 投票阶段
        且 当前阶段 ≠ 遗言阶段
```

⚠️ 只写「白天可自爆」会让白狼王在**别人遗言时**自爆，流程直接乱掉
（遗言被打断，死者的信息丢失）。

## §381 狼人·特殊（9 个）

| 身份 | 技能 | 实现要点 |
|---|---|---|
| **机械狼** | 任意夜间**学习一名玩家**（只能一次）：得知其身份并**习得其技能直至游戏结束**；**夜间单独行动**；**其他狼人全部死亡后才获得狼刀** | 学到的技能要**真能发动**（学女巫就有毒，学猎人就能开枪） |
| **石像鬼** | 每晚查验一人身份；**其他所有狼人出局后**可在夜间袭击；**不能自爆**；**不与狼人互知、不参与袭击** | 与网易一致 |
| **隐狼** | **不能自爆**；**被预言家查验显示好人**；**知道谁是狼人，但狼人不知道谁是隐狼**；**不参与狼人行动**；**狼同伴全出局后才获得狼刀** | ⚠️ 单向可见：隐狼→狼队可见，狼队→隐狼不可见 |
| **禁锢之影** | 每晚**禁锢一名好人**使其当晚技能无法使用；**使用一次后需隔一天**才能再用；使用技能后**和狼人一起行动** | 冷却 = 隔一天，不是隔一晚 |
| **憎恶猎人** | **每个夜晚可猎杀一名玩家**；死亡时可开枪；**死于女巫毒药时不能开枪** | 双刀：狼刀 + 猎杀 |
| **红月使徒** | 白天**遗言、投票以外的任意时间**可自爆；**自爆当晚所有好人技能被封印**；**若为最后一个被放逐的狼人，可存活到下一个白天天亮之后才出局** | 「延迟出局」+「全场封印」 |
| **傀儡师** | 与狼人一起行动；**首夜将一名与狼人相邻的好人变成傀儡** | 傀儡按狼人算？按好人算？见下 |
| **月狼** | 与狼人一起行动；**夜晚不会受到任何伤害** | 免疫夜间一切伤害（狼刀/毒/猎杀/技能） |
| **复仇狼王** | 与狼人一起行动；**每局限一次**：一名狼人被放逐后，**当天夜晚可袭击两名玩家**，**第二天夜晚所有狼人不可发动袭击** | 「双刀换一夜空刀」 |

### 机械狼的「学技能」必须真生效

```
学习(目标):
    已学身份[机械狼] = 身份[目标]
    标记 已学 = 1
    // 之后该狼人行动时，按「已学身份」执行对应技能
```

⚠️ 最常见的偷懒写法：只把身份记下来用于显示，技能不实现。
玩家会立刻发现「我学了女巫却没有毒药」。

⚠️ 学 **猎人** 时还要处理「开枪状态」：
红狼明确「若为猎人告知开枪状态」，即学猎人**能开枪**。

### 傀儡师与「相邻」的定义

```
相邻(狼人) = 座位环上的左右两人
首夜: 选一名「与任意狼人相邻」的好人 → 变成傀儡
```

⚠️ 傀儡的阵营归属原文未明确。**实现时必须自己定**：
建议按「傀儡仍属好人阵营，但狼人获胜时傀儡同胜」处理（类似野孩子的跟随逻辑），
并在规则说明里写清楚。

## §382 第三方（4 个）

| 身份 | 胜利条件 | 实现要点 |
|---|---|---|
| **爱神（丘比特）** | 情侣**双好人** → 随好人胜；**双狼** → 随狼人胜；**一好一狼** → 与情侣组成第三方，**淘汰其他所有阵营** | 情侣形成第三方后，**好人和狼人都还要额外放逐/击杀情侣**（不需处理爱神） |
| **盗宝大师** | 每晚偷一人技能，被偷者当晚不能发动技能；不能重复偷同一人。**胜：好人与狼人存活人数均 ≤ 1** | 胜利条件是「两边都剩不到 2 人」——**不是加入任何一边** |
| **野孩子** | 首夜选一名「崇拜者」；**崇拜者出局后，野孩子在下一个白天或夜晚加入狼人阵营**，之后每晚参与杀人、与狼人互知 | 阵营**运行时可变**；变身时点有「下一个白天或夜晚」的窗口 |
| **窃贼** | 首夜从**两张角色牌**中选一张作为自己的角色；**有狼人必须选狼人** | 板子池要**多放 2 张**（人数 + 2） |

### 爱神的三分支判定

```
情侣 = (A, B)
若 阵营(A) = 好人 且 阵营(B) = 好人:
    爱神胜 = 好人胜
若 阵营(A) = 狼 且 阵营(B) = 狼:
    爱神胜 = 狼人胜
否则:                                   // 一好一狼
    第三方 = {A, B, 爱神}
    爱神胜 = 「除这三人和已死者外，场上无人存活」
    // 同时：好人和狼人的胜利条件都追加「情侣必须出局」
```

⚠️ **第三方成立后，好人和狼人的原胜利条件会被「加一条」而不是「改掉」**。
写成「消灭第三方就算赢」会让狼人只要杀情侣就获胜，破坏平衡。

### 盗宝大师的胜负必须独立判定

```
若 存活好人数 ≤ 1 且 存活狼人数 ≤ 1 → 盗宝大师胜
```

⚠️ 这个条件会与「好人胜 / 狼人胜」**同时成立**。
必须定优先级：建议 **盗宝大师优先**（否则这个身份几乎赢不了）。

### 野孩子的变身时点

```
崇拜者死亡:
    标记 待变身 = 1
下一个白天开始 或 下一个夜晚开始:
    若 待变身 = 1:
        加入狼人阵营
        与狼人互知
        获得狼刀
        待变身 = 0
```

⚠️ **变身不能在崇拜者死亡的同一瞬间完成**：原文写「下一个白天或夜晚」，
说明中间有一个观察窗口（场上要先知道崇拜者死了）。

## §386 夜间唤醒顺序（按板子分别定义）

红狼的夜间顺序**不是全局统一**的，每个板子有自己的顺序。这是它和网易最大的实现差异。

| 板子 | 顺序 |
|---|---|
| **基础板** | 守卫 → 狼人 → 预言家 → 女巫 → 猎人（确认开枪状态） |
| **狼狼大逃亡** | **憎恶猎人（选袭击对象）** → 预言家 → 女巫 |
| **疯狂动物园** | ① 企鹅（选冰冻）→ ② 狼人（选袭击） |
| **爱神** | **爱神（首夜指定情侣）** → 其后正常 |
| **狼美人与老酒鬼** | 狼人击杀 → **狼美人（魅惑）** → 其余正常 |
| **失踪的宝物** | **盗宝大师（偷技能）** → 其余正常 |
| **月影传说** | **禁锢之影（禁锢）** → **月夜祭司（确认机能状态）** → 其余 |
| **小女孩** | **小女孩 与 狼人 同为第一行动位**（偷看） → 其余 |
| **机械狼** | 守卫 → 狼人 → 女巫 → **通灵师（睁眼不发动）** → 猎人 → **机械狼（学人）** → **通灵师（发动查验）** → 机械狼（按学习身份行动） |
| **黑狼王与织梦人** | **织梦人（指定梦游）** → 其余 |
| **石像鬼与守夜人** | **守夜人** → 其余 → **石像鬼（最末位）** |
| **野孩子** | **野孩子（首夜选崇拜者）** → 其余 |

### 机械狼板子的顺序是全册最绕的，值得单独记住

```
① 守卫
② 狼人袭击
③ 女巫用药
④ 通灵师睁眼（不发动技能）      ← 只是确认在场
⑤ 猎人确认开枪状态
⑥ 机械狼学习（若学到猎人，告知开枪状态）
⑦ 通灵师发动查验（查机械狼显示其学习后的身份）
⑧ 机械狼按学习身份使用技能
```

**为什么通灵师要睁眼两次**：
第 ④ 步是「告知通灵师今晚可以行动」，第 ⑦ 步才是「实际查验」。
中间插进机械狼的学习，是为了让「通灵师查到的是机械狼学完之后的身份」这条规则成立。

⚠️ **不要图省事把顺序拍平成「守卫→狼→女巫→预言→其他」**：
机械狼板子的核心机制就是靠这个错位成立的，拍平了整局就没意义了。

## §387 警长与吞警徽（单爆/双爆并存）

红狼的警长规则与网易接近，但有三个细节不同：

```
竞选时机：首夜过后的首个白天
上警：所有玩家均可报名
发言：警上按上帝给的顺序
投票：警下玩家对警上投票，得票最多者当选
退水：警上发言后可退水，退水者不再有被选举权
平票：进入平票发言 → 再投 → 再平 → 警徽流失
```

### 三条细节差异

**① 「单狼自爆吞警徽」和「双狼自爆吞警徽」是两种可选规则，不是二选一。**

红狼原文同时列出：
- 单狼自爆 → 本轮无警徽，自动进入夜晚
- 双狼自爆 → 第一爆后**第二轮白天仍进入竞选环节**，要吞需**再安排一名狼人自爆**

→ 这是**房规开关**（`双爆吞警徽 = 0/1`），不是固定规则。
网易默认双爆，红狼两个都支持。

**② 红狼明确写了「退水者不再拥有被选举权」。**
网易的表述是「退水的玩家没有投票权」—— **两者说的是不同的事**：
红狼强调**被选举权**（退水就不能再当选），网易强调**投票权**。
实现时两条都要有：

```
可被选 = 上警 且 未退水
可投票 = 未上警
```

**③ 警长有「归属权」**（指定发言顺序），并且**总在最后一个发言**。

### 吞警徽的状态机

```
竞选阶段：1上警 2发言 3退水 4投票 5PK 6已产生 7流失 8暂停(双爆第一爆)

自爆(在竞选期间):
    若 双爆开关 = 0:
        警徽流失; 阶段 = 7
    否则:
        若 暂停次数 = 0 → 暂停次数 = 1; 阶段 = 8    // 次日恢复竞选
        否则           → 警徽流失; 阶段 = 7
```

⚠️ **必须用 if/else，不能写成两个平级 IF**：
第一段把「暂停次数」置 1 后，第二段的条件立刻成立，
同一帧就把阶段 8 覆盖成 7 —— **双爆退化成单爆**（第三十三册 §340 实踩）。

## §388 自爆规则的四个例外

红狼对自爆的限制比网易更细，有四个**明确的时点例外**：

| 例外 | 说明 |
|---|---|
| **① 白狼王不可在投票环节自爆** | 投票已经开始，带人会打断计票 |
| **② 白狼王不可在遗言环节自爆** | 遗言被打断，死者信息丢失 |
| **③ 暴狼同样「投票和遗言阶段除外」** | 与白狼王一致 |
| **④ 红月使徒「遗言、投票以外的任意时间」可自爆** | 同上，但明确写了「任意时间」 |

```
可自爆(玩家) =
    身份.可自爆 = 1
    且 当前阶段 ∉ {投票, 遗言}
```

⚠️ 这条如果只写「白天可自爆」，白狼王会在别人遗言时自爆，
**死者遗言直接消失**，玩家会觉得游戏坏了。

### 红月使徒的两个额外效果

```
自爆(红月使徒):
    死亡(红月使徒)
    当晚封印所有好人技能 = 1        ← 只封好人，不封狼
    若 红月使徒是最后一个被放逐出局的狼:
        延迟出局 = 1                ← 存活到下一个白天天亮之后
```

⚠️ 「最后一个被放逐出局的狼」这个条件很绕：
它要求 **① 红月使徒是被放逐死的**（不是被刀/被毒）**② 他是最后一个出局的狼**。
两个条件同时成立才触发延迟。写成「最后一个狼死就延迟」，
会让被刀死的红月使徒也复活。

## §389 遗言规则（红狼特有的一条）

| 死因 | 有遗言？ |
|---|---|
| **首夜**任何夜间死亡 | ✅ 有 |
| **首夜平安夜** → 此后**所有**夜间死亡 | ❌ **没有**（红狼特有） |
| 第 2 夜及以后夜间死亡（首夜有死者） | ❌ 没有 |
| 白天被放逐 | ✅ 有 |
| 白天被枪 / 被决斗 / 被技能 | ✅ 有 |
| **被白狼王带走** | ❌ **没有** |
| **狼人自爆** | ✅ 有（白狼王发动技能除外） |
| **第一天警长竞选时狼人自爆** | 第一天夜晚死者**依然可发遗言** |

### 「首夜平安夜」为什么需要单独记一个状态

```
首夜结束:
    若 首夜死亡人数 = 0:
        首夜平安 = 1
    否则:
        首夜平安 = 0

任何夜间死亡:
    有遗言 = (当前夜次 = 1)         // 永远是首夜才有
```

⚠️ 红狼的规则是：**首夜平安 → 第 2 夜开始真的一个夜间遗言都没有**。
但注意：**第 1 夜本身如果没人死，也就不存在「给谁遗言」**。
所以这条规则的实际作用是 —— **防止玩家误以为「首夜平安，那第二夜死了应该有遗言」**。
代码里不用加额外分支，**但规则说明必须写**，否则玩家会来争论。

### 遗言的「同一时间死亡」

```
猎人枪杀 / 白狼王带人的目标 → 视为与发动技能者同一时间死亡
女巫毒杀目标              → 视为夜晚死亡
```

**为什么重要**：影响「谁先发言」和「谁能看到谁的死讯」。
写成「后死的人后发言」会让猎人的枪杀目标和猎人自己分两批公布，
场上会多出一轮不必要的信息。

## §390 胜负判定：屠边 + 三套第三方

### 通用

```
好人胜：淘汰所有狼人 + 所有第三方
狼人胜：屠边 —— 所有神职出局  或  所有平民出局
```

⚠️ **红狼的「好人胜」包含第三方**（原文：「淘汰所有狼人及第三方阵营玩家即胜」）。
网易的第三方是独立判定，红狼是「好人要清场」。这是又一个不能混用的点。

### 三套第三方判定

**爱神**

```
情侣双好人 → 爱神随好人胜
情侣双狼   → 爱神随狼人胜
情侣一好一狼 → 第三方 = {情侣, 爱神}
              第三方胜 = 其他阵营全灭
              并且：好人/狼人 原胜利条件 + 「情侣必须出局」
```

**盗宝大师**

```
盗宝大师胜 = 存活好人数 ≤ 1 且 存活狼人数 ≤ 1
好人胜     = 盗宝大师 + 所有狼人 出局
狼人胜     = 所有好人出局
```

⚠️ 盗宝大师的条件会和好人/狼人**同时成立**，必须定优先级。
建议 **盗宝大师优先**，否则这个身份几乎赢不了。

**野孩子**

```
跟随所属阵营（人类 / 狼人）
⚠️ 结算优先于变身：
   崇拜者死亡时，若已达成好人胜 → 游戏立即结束，野孩子与好人同胜
   崇拜者死亡时，若已达成狼人胜 → 游戏立即结束，狼人胜，野孩子与好人同败
   野孩子先于崇拜者死亡 → 永远属人类阵营
```

⚠️ 「结算优先于变身」是红狼独有的精细规则：
如果崇拜者的死同时导致游戏结束，**野孩子来不及变身**，按原阵营算。

## §393 校验清单与十个坑

### 校验清单（做红狼作品必跑）

| # | 断言 | 抓什么错 |
|---|---|---|
| 1 | 板子池长度 = 人数 | 少发/多发 |
| 2 | 女巫可自救 = 1 时，女巫被刀能救自己 | 抄成网易版 |
| 3 | 好人胜条件包含第三方 | 抄成网易版 |
| 4 | 白狼王在投票阶段不能自爆 | 时点例外丢失 |
| 5 | 首夜平安后第 2 夜死亡无遗言 | 只按夜次判 |
| 6 | 老酒鬼被毒延迟一天死 | 写成当场死 |
| 7 | 老酒鬼延迟死亡在「发言后投票前」 | 放进投票后 |
| 8 | 厚皮狼只对「夜间猎人击杀」多命 | 变成打不死 |
| 9 | 熊被冰冻 / 死亡时不咆哮 | 无条件咆哮 |
| 10 | 洞悉之眼杀狼后销毁 | 眼一直传，每夜杀一狼 |
| 11 | 招魂师幽魂「可投票但不计存活」 | 用一个变量表达四件事 |
| 12 | 牧羊犬并列时失败（不随机） | 强度翻倍 |
| 13 | 机械狼学到的技能真能发动 | 只记录不实现 |
| 14 | 野孩子变身晚于崇拜者死亡 | 同帧变身 |
| 15 | 盗宝大师优先于好人/狼人胜 | 永远赢不了 |
| 16 | 红月使徒延迟出局需「被放逐 + 最后一个狼」 | 被刀也复活 |
| 17 | 双爆第一爆是「暂停」不是「流失」 | 两个平级 IF 覆盖 |
| 18 | 结算页有返回 / 再来一局（铁律 7） | 打完卡死 |

### 十个坑

1. **把红狼当网易版写** —— 女巫自救、好人胜含第三方、白狼王时点，三条必错。
2. **「红狼」当成身份** —— 它是游戏名。之前本 skill 就犯过这个错，已改正。
3. **夜间顺序拍平** —— 机械狼板子的核心机制靠错位成立。
4. **老酒鬼当场死** —— 延迟死亡要跨一个白天。
5. **厚皮狼对所有死因多命** —— 只对夜间猎人击杀。
6. **熊无条件咆哮** —— 死亡/冰冻/相邻死光都要静音。
7. **洞悉之眼不销毁** —— 每夜稳定杀一狼，好人无敌。
8. **用一个「存活」表达四件事** —— 招魂师一定写错。
9. **白狼王遗言阶段自爆** —— 死者遗言消失。
10. **只做 12 人板** —— 红狼的 6~11 人是它的教学曲线，丢掉就没了特色。
