# 狼人杀完全手册：身份、板子、警徽流与自爆（第三十三册，§320–§348）

> 第三十一册 §299 讲的是「三段式骨架能跑起来」。这一册解决另一半问题：
> **身份写不全、板子配不对、警徽流不会算、自爆流程错**。
> 只做「狼人 + 村民 + 预言家 + 女巫」的狼人杀，玩家三分钟就看穿了。
>
> 本册的信息来自网易《狼人杀-官方正版》官网规则页、官方板子公告、百度百科角色表，
> 以及维基学院/Fandom 的警长规则词条。**身份的技能数值会随版本调整**，
> 所以本册的重点不是背数值，而是给出**能把任意身份翻译成代码的四要素**
> （§322）与**板子表结构**（§320 / §335）——换版本只需要改表，不用改状态机。

---

## §320 板子是一张表，不是一段代码

新手最容易犯的结构性错误：为一个板子写一套脚本。结果 12 个板子 = 12 套状态机，
改一个规则要改 12 处，而且越改越不一致。

正确做法：**板子 = 数据，流程 = 引擎**。

```
板子表（每行一个板子）
  名称 | 人数 | 板子池（身份编码数组） | 规则开关
```

规则开关是几个布尔位，只控制**流程差异**，不控制身份技能：

| 开关 | 影响什么 | 典型取值 |
|---|---|---|
| `有警长` | 首日是否有竞选阶段 | 6 人明牌场 = 否；12 人标准场 = 是 |
| `屠边` | 胜负判定方式（§345） | 12 人 = 屠边；6 人明牌 = 屠城 |
| `明牌` | 出局是否翻身份 | 萌新场 = 明牌；标准场 = 暗牌 |
| `双爆吞警徽` | 自爆吞警徽的规则（§341） | 官方默认双爆；部分房规单爆 |
| `首夜遗言` | 夜间死亡是否留遗言（§342） | 官方 = 仅首夜有 |
| `自爆遗言秒数` | 自爆后能否发言 | 官方 = 30 秒（可发言） |

**关键判断**：如果一个「新板子」只改了身份组合，它就是**表里新增一行**；
只有它改了流程（比如「无警长」「屠城」），才需要动开关。
按这个标准，本册 §332–§334 列出的 40+ 个板子，**没有一个需要新写状态机**。

## §321 身份总表：按「触发时机」分成七类

身份有 60 多个，逐个记技能没有意义。真正决定代码结构的是**它什么时候被触发**：

| 类 | 触发时机 | 代码位置 | 数量 |
|---|---|---|---|
| **A 夜间主动** | 每晚固定顺序醒来 | 夜间队列（§343） | 最多 |
| **B 白天主动** | 玩家自己决定何时翻牌 | 白天插入点（§326） | 少 |
| **C 死亡触发** | 出局瞬间 | 死亡结算链（§344） | 少 |
| **D 被动/光环** | 持续生效，无需行动 | 判定函数里加一条 | 中 |
| **E 狼人·带刀** | 参与夜间狼刀 | 狼人行动段 | 中 |
| **F 狼人·特殊** | 不见面 / 免疫 / 反伤 | 可见性表 + 免疫表 | 中 |
| **G 第三方** | 自己的胜负条件 | 独立胜负判定（§345） | 4 |

> **这一列「代码位置」是本册的价值所在**：看到一个新身份，先判断它属于哪一类，
> 就知道该往哪写，而不是「又得加一个状态」。

## §322 每个身份都必须回答四个问题

不管技能多复杂，翻译成代码时只填四个字段。缺一个就会出 bug。

```
① 阵营      好人 / 狼人 / 第三方            → 影响胜负判定
② 触发窗口  夜(第几晚起) / 白天 / 死亡 / 常驻  → 影响队列位置
③ 目标合法性 能否选自己 / 死人 / 已选过 / 狼队友 → 影响交互过滤
④ 结算时点  立即 / 天亮 / 次日 / 出局时       → 影响死亡链顺序
```

举三个例子说明「④ 结算时点」为什么最容易被忽略：

| 身份 | 若写成「立即」会怎样 | 正确时点 |
|---|---|---|
| 猎魔人 | 当晚就知道对方死没死 → 信息提前泄露 | **次日**出结果 |
| 纯白之女 | 验到狼当场出局 → 女巫还救不救？顺序乱 | **当夜**出局（第 2 夜起） |
| 夜之贵族 | 选完夜仆立刻死 → 女巫没有救人窗口 | **下一晚天亮时**出局 |

**一条通用规则**：**「信息类技能立即生效，伤害类技能延后结算」**。
因为信息只影响一个玩家的判断，伤害会影响整条死亡链。

## §323 好人神职·夜间主动（一）：查验与情报

| 身份 | 技能 | 目标合法性 | 结算时点 |
|---|---|---|---|
| **预言家** | 每晚查验一人：好人 / 狼人 | 不能选自己；可重复查同一人（无意义） | 当夜 |
| **魔镜少女** | 每晚查验一人**具体身份**（能查出隐狼） | 不能选自己 | 当夜 |
| **纯白之女** | 每晚查验一人具体身份；**第 2 夜起验到狼人，该狼人当夜出局** | 不能选自己 | 当夜 |
| **守墓人** | 每晚得知**上一个白天被放逐者**是好人/狼人 | 无目标（自动） | 当夜 |
| **觉醒预言家** | 每晚选**两名**玩家窥视，只回答「其中是否有狼」 | 必须两个不同的人 | 当夜 |
| **狼巫**（狼） | 每晚查验**除狼人阵营外**一人具体身份；第 2 夜起验到纯白之女则其出局 | 不能选狼 | 当夜 |
| **熊** | 天亮时若熊存活且左右**相邻存活者**中有狼，法官宣布「熊咆哮了」 | 无目标（自动） | 天亮 |
| **白兔** | 得知每晚/每白天的**死因**，可与死者交流 | 无目标 | 天亮 |
| **追魂者** | 探查一人是否有「复活痕迹」；自身免疫一次致命效果 | 不能选自己 | 当夜 |

**实现要点：查验结果必须编码成数字，不要存字符串。**

```
查验结果[目标] = 0  未查
              = 1  金水（好人）
              = 2  查杀（狼人）
              = 3  具体身份编码（魔镜少女 / 纯白之女）
```

字符串比较在 Scratch 里大小写、空格、全半角都会出问题；数字永远不会错。
**而且数字能直接用于「警徽流」的自动解读**（§339）。

⚠️ **隐狼对预言家显示为好人**（§329）：查验函数里必须先判 `身份 = 隐狼` 返回 1，
再走正常阵营判断。放在阵营判断之后，隐狼就白设计了。

## §324 好人神职·夜间主动（二）：保护与干扰

| 身份 | 技能 | 硬约束（最容易漏） |
|---|---|---|
| **女巫** | 解药救当夜被刀者；毒药毒一人 | **每晚最多用一瓶**；**不可自救**；解药只有一瓶 |
| **守卫** | 每晚守一人，免疫狼刀 | **不能连续两晚守同一人**；与女巫解药同目标 → **同守同救，该玩家仍死**（「奶穿」） |
| **摄梦人** | 每晚**必须**选一人成为梦游者，免疫夜间伤害 | **摄梦人夜间出局时梦游者一并出局**；**同一人连续两晚被摄梦也出局**；梦游者自己不知道 |
| **魔术师** | **每晚最先行动**，交换两名玩家的号码牌，当晚有效 | 交换发生在所有技能之前；交换后所有技能按新号码结算 |
| **流光伯爵** | 第 2 晚起每晚庇护一人，免疫夜间伤害 | 不能连续两晚同一人；**蚀日侍女吞噬被庇护者会反噬** |
| **觉醒守卫** | 每天可选在**夜晚**或**白天放逐发言阶段**使用一次觉醒守护 | 被守护者**不会以任何方式出局**；不能连续两天同一人；白天守护被放逐 → 显示平安日、无遗言、直接入夜 |
| **炼金魔女** | ①未明之雾：夜间指定 3 名不同玩家，**当夜狼人必须从这 3 人中选目标**；②法老之蛇：获知当夜狼刀目标，并在公布出局信息前决定是否救 | 各一次；**持有法老之蛇时白天流程变为「先发言后公布死讯」** |
| **奇迹商人** | **每夜第一个行动**，选一名其他玩家给一次性技能（查验/毒/守护） | 每局一次；**给到狼人 → 狼人得不到技能，且次日商人出局** |
| **子狐** | 第 2 晚起迷惑一人；迷惑到狼人 → **整个狼队当夜不能袭击**；迷惑到狼美人 → 狼美人当夜不能魅惑 | 一局仅一次 |
| **噩梦之影**（狼） | 每晚**最先**恐惧一人，其当夜无法使用技能；若目标是狼人 → **整个狼队当夜不能袭击** | 不能连续两晚同一人；**首夜恐惧时与其他狼不互知** |
| **蚀时狼妃**（狼） | 每晚**率先**把一人封锁到时间夹缝：当晚好人对该人的验人/毒/守护**都视为对自身释放** | 技能生效的**下一夜永久失去技能** |

**「同守同救」必须显式实现，不能靠「有保护就活」的简化模型：**

```
死亡判定（单人）：
  受狼刀?   → 是
  有守卫?   → 免疫
  有解药?   → 免疫
  守卫 且 解药 同时存在 → 死        ← 奶穿
  其他保护(庇护/觉醒守护/梦游) → 免疫，且不受奶穿影响
```

⚠️ 把「有保护就活」写成 `if 守卫 or 解药 then 活`，奶穿规则就永远丢失了。
这条规则在真实对局里影响极大（守卫和女巫的第一晚配合），不能省。

## §325 好人神职·夜间主动（三）：特殊机制

| 身份 | 技能 | 关键细节 |
|---|---|---|
| **猎魔人** | 第 2 晚起每晚狩猎一人：对方是狼 → **次日**对方出局；对方是好人 → **次日**猎魔人出局 | **女巫毒药对猎魔人无效**（免疫毒） |
| **乌鸦** | 每晚诅咒一人，该人**下一个白天放逐投票额外 +1 票** | 不能连续两晚同一人 |
| **河豚** | 放逐投票后**主动翻牌**，带走所有**在本次投票中投给河豚的人** | 一局一次；**狼队夜间落刀河豚 → 天亮河豚翻牌出局，狼美人技能当天白天失效** |
| **定序王子** | 每个白天**第一次**放逐投票结束后翻牌，逆转时空回到投票前重投 | 全场一次；重投前获得额外一次发言 |
| **白昼学者** | 第 2 晚起用「时波转化器」**增幅**或**削弱**目标 | 增幅、削弱**各一次**，**同一晚只能用其一** |
| **觉醒女巫** | 解药 + 毒药调配（可毒 3 次） | 毒药需 1/2/3 名**协助者**分别表态，**全员同意才生效**；女巫不知道协助者选择 |
| **觉醒愚者** | 白天被放逐时翻牌**免疫本次放逐**并失去秘密之身；夜间可用秘密之身替一人抵消一次伤害 | 若目标未受伤或已被救 → 改为替自己抵消；**为谁抵消都会失去秘密之身** |

### 白昼学者的增幅/削弱对照表（必须逐身份判断）

| 目标身份 | 增幅效果 | 削弱效果 |
|---|---|---|
| 预言家 | 当夜**额外验一次** | 当夜**不能验** |
| 女巫 | 当夜**额外毒一次** | 当夜**不能用技能** |
| 守卫 | 当夜**额外守一次** | 当夜**不能守** |
| 狼人 | 当夜**额外袭击一次** | **整个狼队**当夜不能袭击 |
| 其他神/民 | 无效果 | 神职不能发动技能 |

⚠️ **削弱到狼人 = 削弱整个狼队**，不是只削弱那一个狼。这条不对称是白昼学者最容易被写错的地方。

**白昼学者 × 寂夜导师的碰撞规则**（时波之乱板子的核心）：

```
同一名好人当夜同时被白昼学者和寂夜导师作用
    → 双方技能全部失效，且该玩家出局
同一名狼人被两者作用（可以是不同狼）
    → 双方技能失效，且寂夜导师出局
```

## §326 好人神职·白天主动与死亡触发

| 身份 | 触发 | 技能 | 硬约束 |
|---|---|---|---|
| **骑士** | 白天放逐发言阶段，**随时翻牌** | 决斗一人：对方是狼 → 狼出局并**立即进入黑夜**；对方是好人 → 骑士出局，**继续原本的发言流程** | 翻牌即公开身份 |
| **白痴 / 愚者** | **被放逐时** | 翻牌免疫本次放逐；之后**可发言、不可投票**，也**不可被投票**；需再被杀一次才死 | **非放逐死亡（被刀/被毒/被枪）无法发动，立即死亡** |
| **猎人** | **被狼刀** 或 **被放逐** | 亮身份并枪杀一人 | **被女巫毒杀不能开枪**；**被狼王带走可以开枪** |
| **狼王**（狼） | 出局时 | 带走一人 | **被猎人带走仍可开枪**；**殉情、被毒不能开枪** |
| **觉醒猎人** | 出局时 | 可选**正序或逆序**巡猎，使该方向**最近的一名狼人**出局 | 夜间出局时，被巡猎的特殊狼人**技能无效** |
| **白猫** | **任何原因出局** | 翻牌并**额外存活至下一次放逐投票阶段后** | 是「延迟死亡」不是「免死」，票照算 |
| **河豚** | 放逐投票后主动翻牌 | 见 §325 | 一局一次 |

**「不能开枪」的完整判定表**（这是狼人杀里最经典的规则细节）：

| 死因 | 猎人 | 狼王 |
|---|---|---|
| 被狼刀 | ✅ 可开枪 | ✅ 可开枪 |
| 被放逐 | ✅ 可开枪 | ✅ 可开枪 |
| 被女巫毒 | ❌ 不可 | ❌ 不可 |
| 被猎人枪 | — | ✅ 可开枪 |
| 被狼王带 | ✅ 可开枪 | — |
| 殉情（狼美人/摄梦人连带） | ❌ | ❌ |
| 被骑士决斗 | — | — |

**代码里怎么表达**：不要给每个身份写一遍，而是给死亡事件打一个「死因标签」：

```
死因：1=狼刀 2=放逐 3=毒 4=枪 5=殉情 6=技能
可开枪 = (死因 = 1 或 2 或 4)
```

⚠️ 用 `死因` 一个数字解决所有身份的所有组合。如果写成
`if 身份=猎人 and (死因=狼刀 or 死因=放逐 or 死因=枪)`，狼王要再写一遍，
未来加一个「毒猎人的狼」就要改两处 —— **一定会漏**。

## §327 好人·被动与平民变体

| 身份 | 类型 | 说明 |
|---|---|---|
| **平民** | 无技能 | 标准场 4 张 |
| **羊驼** | 平民变体 | 动物梦境板子里的「平民」，仅名字不同 |
| **漩涡平民** | 平民变体 | 狼王计划板子；操控全场投票（按板子说明书） |
| **老流氓** | 被动 | 民间板子；被放逐时不翻牌 / 抗推（按房规） |
| **村长 / 长老** | 被动 | 民间板子；通常「被狼杀需两次」或「投票权重更高」 |
| **野孩子** | 被动 | 首夜选一名「榜样」；**榜样死亡后野孩子变成狼人** |
| **混血儿** | 被动 | 首夜选一名「亲人」，与其同阵营胜负（民间规则差异大） |
| **禁言长老** | 夜间主动 | 每晚禁言一人，该人白天不能发言 |
| **炸弹人** | 死亡触发 | 出局时带走一人（部分板子为「被投出时」） |
| **咒狐** | 特殊 | 咒狐场专属，规则按板子说明书；实现时按「第三方」处理最安全 |

⚠️ **被动类身份不需要在夜间队列里占位**，但**必须在判定函数里加一条**。
最常见的漏洞：实现了野孩子，却忘了在「榜样死亡」时改阵营 ——
导致野孩子永远是好人，整局少一个狼。

## §328 狼人（一）：基础与带刀

所有狼人的共同点：**知道彼此身份**（除特殊狼）、**夜间共同选刀**、**多数可自爆**。

| 身份 | 可自爆 | 可自刀 | 技能 | 特殊限制 |
|---|---|---|---|---|
| **狼人（普狼）** | ✅ | ✅ | 每晚与狼队共同刀一人 | — |
| **狼王** | ✅ | ✅ | 出局时可带走一人 | 被毒/殉情不可开枪 |
| **白狼王** | ✅ | ✅ | **自爆时可带走一人** | 与狼王不同：带人绑在自爆上，不是出局上 |
| **狼美人** | ❌ | ❌ | 每晚参与袭击后**单独睁眼**魅惑一人；**出局时昨夜被魅惑者殉情** | 不能自爆、不能自刀 |
| **血月使徒** | ✅ | ✅ | **自爆后直接入夜，当晚所有好人技能被封印** | 若为最后一个被放逐的狼，**可存活到下一个白天天亮后**才出局 |
| **噩梦之影** | ✅ | ✅ | 每晚最先恐惧一人 | 见 §324 |
| **蚀时狼妃** | ✅ | ✅ | 每晚率先封锁一人 | 见 §324 |
| **狼巫** | ✅ | ✅ | 每晚查验非狼一人 | 见 §323 |

| **饿狼** | ✅ | ✅ | 每晚**吞噬**一人：该人白天不能发言/投票/被投，也不能被任何技能针对 | 吞噬不是击杀，是「隔离」 |

```
带刀狼 = 普狼 / 狼王 / 白狼王 / 狼美人 / 血月 / 噩梦 / 蚀时 / 狼巫 / 夜之贵族 / 饿狼 / 蓝狼 / 猩红

```

⚠️ 「等其他人全出局才能刀」这句话的判定是
**`存活狼数(不含自己) = 0`**，不是 `存活狼数 = 1`。
写成 `=1` 会让两个同类型特殊狼永远开不了刀。

```

```

## §330 第三方

| 身份 | 阵营 | 胜负条件 | 实现要点 |
|---|---|---|---|
| **丘比特（爱神）** | 首夜好人 | 连接两人成为情侣；**情侣跨阵营 = 第三方**，情侣全灭则第三方失败 | 首夜行动；殉情是**双向**的（一人死另一人立刻死） |
| **盗贼** | 首夜特殊 | 从**两张底牌**中选一张作为自己的身份 | 板子池要**多放 2 张**（人数+2）；选完剩下的牌作废 |

**第三方的判定必须独立于「狼人 vs 好人」：**

```
胜负判定顺序：
① 若存在存活的第三方且其条件达成 → 第三方胜（先判）
② 若狼人全灭 → 好人胜
③ 若屠边/屠城条件达成 → 狼人胜
④ 否则继续
```

⚠️ 把第三方塞进「好人/狼人」二选一，丘比特情侣永远赢不了 —— 这是最常见的设计缺陷。

## §334 板子的数据结构与合法性校验

### 存法：一张表 + 一个池

```
板子名表  = [标准场, 进阶场, 白狼王守卫, ...]        ← 舞台列表
板子人数  = [12, 12, 12, ...]
板子池    = ["1,1,1,1,2,2,2,2,3,4,5,6", ...]         ← 逗号分隔的身份编码
板子开关  = ["1,1,0,1,1", ...]                       ← 有警长,屠边,明牌,双爆,首夜遗言
```

> **为什么身份池用「逗号分隔的字符串」而不是二维列表**：
> Scratch 的列表只有一维，二维要靠 `行*列+列` 手算索引，容易错。
> 用 `1,1,1,1,2,2,2,2,...` 一个字符串，取第 i 个身份时用「按逗号拆分取第 i 段」。
> 本工程的做法是**开局一次性拆进「身份池」列表**，之后只按索引访问，运行期零成本。

### 五条合法性校验（做板子编辑器时必须有）

| 校验 | 条件 | 报错示例 |
|---|---|---|
| 人数匹配 | `长度(身份池) = 人数`（盗贼局 `人数+2`） | 「13 张身份配 12 人」 |
| 狼人存在 | `狼人数 ≥ 1` | 「没有狼人」 |
| 民数非负 | `民数 ≥ 1`（除特殊板子） | 「神太多，没有民」 |
| 神数非负 | `神数 ≥ 1` | 「全民板子无法屠边」 |
| 唯一性 | 同一身份不超过 1 张（普狼/民除外） | 「两个预言家」 |

**代码骨架（伪代码）**：

```
校验板子(编号):
    池 = 拆分(板子池[编号])
    若 长度(池) ≠ 板子人数[编号] → 返回 "人数不匹配"
    狼 = 0; 神 = 0; 民 = 0
    对 i = 1..长度(池):
        若 池[i] ∈ 狼人编码集 → 狼+1
        否则若 池[i] ∈ 平民编码集 → 民+1
        否则 → 神+1
    若 狼 = 0 → 返回 "没有狼人"
    若 民 = 0 且 板子人数[编号] > 8 → 返回 "没有平民（屠边退化）"
    返回 "OK"
```

⚠️ **校验要放在「开始游戏」按钮前**，而不是开局后。
玩家配了一个坏板子，开局三秒才发现「没有狼人」，体验极差。

## §335 警长：五阶段竞选

警长是**附加身份**，不属于任何阵营（但实际有阵营倾向）。
它带来三个权力：**1.5 票**、**决定发言顺序**、**归票权**。

竞选发生在**第一个黑夜流程结束、宣布首夜死讯之前**：

```
阶段 1  上警       法官宣布「请上警的玩家举手」，15 秒
阶段 2  发言       随机顺序，每位上警玩家发言
阶段 3  退水       上警玩家可退出竞选（退水者失去投票权）
阶段 4  投票       只有「没上警」的玩家有投票权
阶段 5  公布       宣布警长 → 再宣布首夜死讯 → 死者留遗言
```

**关键顺序**：`先选警长，再公布死讯`。反了的话，死者如果上警了怎么办？
（答案：**死者的警长资格无效，警徽重新处理** —— 见 §336 边界情况）

### 代码里的阶段编码

```
警长阶段 = 0  未开始
         = 1  上警
         = 2  发言
         = 3  退水
         = 4  投票
         = 5  平票PK
         = 6  已产生警长
         = 7  警徽流失
```

⚠️ **`7 警徽流失` 必须是一个显式状态**，不能靠「警长 = 0」推断。
因为 `警长 = 0` 同时表示「还没选」和「流失了」，两者在流程上完全不同
（前者要继续选，后者永远不选）。

## §336 竞选的六种边界情况

这六种情况是「代码能跑但规则不对」的高发区，逐个给判定：

| # | 情况 | 正确结果 |
|---|---|---|
| 1 | 只有 1 人上警 | **直接当选**，不投票 |
| 2 | 没人上警 | **警徽流失** |
| 3 | 所有人上警，退水后仍 ≥2 人 | **警徽流失**（没有人有投票权） |
| 4 | 退水后只剩 1 人 | **直接当选** |
| 5 | 所有人退水 | **警徽流失** |
| 6 | 投票平票 | **平票者 PK 发言 → 重投**；再次平票 → **警徽流失** |

**PK 的投票权限制**（最容易漏）：
只有「**原先没上警**」的玩家有投票权。退水的、第一轮落选的，**都没有**。

```
有投票权 = (未上警) 且 (存活)
```

⚠️ 如果 PK 时把「退水者」也算进投票人，会出现「退水后反而能投票」的荒谬结果。

### 警长的死亡与警徽去向

警长以**任何方式**死亡（被刀/被毒/被放逐/被枪），都有两个选择：

```
① 移交警徽 → 指定一名存活玩家成为新警长
② 撕毁警徽 → 本局不再有警长
```

⚠️ **警长被「白猫」延迟死亡时，警徽不移交** —— 因为人还没真死。
判定要用「最终死亡」而不是「首次出局」。

## §337 警徽流是什么：一个「死后留言」协议

**定义**：警长（通常是预言家）在发言时**提前声明**：
「如果我今晚死了，警徽给 X；如果 X 是狼，就给 Y。」

为什么要这么做？因为**夜里死的人通常没有遗言**（§342）。预言家验了一晚上人，
天亮被刀，信息带进棺材 —— 这是好人阵营最大的损失。

警徽流就是**用「警徽交给谁」这个动作来传递验人结果**：

| 警长死后的动作 | 含义 |
|---|---|
| 警徽交给 X | **X 是金水**（好人）—— 预言家不会把 1.5 票送给查杀 |
| **撕毁警徽** | 最后一晚验的是**查杀**（或没有可信的人可交） |
| 交给一个已经被查杀的人 | 极端情况：表示「我判断错了」或「警徽流被狼人污染」 |
| 没留警徽流就死了 | 信息丢失，只能靠场上推理 |

**经典的双验人流**：
「我今晚验 3 号。如果 3 号是金水，警徽给他；如果 3 号是查杀，警徽给 7 号（昨天的金水）。」
这样一次死亡能传递**两条**信息：3 号的身份 + 7 号是可信的金水。

---

## §338 警徽流的编码与实现

### 数据结构：三张平行列表

```
警徽流_顺序  = [3, 7, 0]       ← 依次要验的人，0 = 空位
警徽流_去向  = [3, 7, 0]       ← 对应的警徽接收人
警徽流_指针  = 1               ← 当前第几顺位
警徽_持有者  = 0               ← 0 = 无人/流失
```

**为什么「顺序」和「去向」要分开**：验 3 号如果是金水给 3，如果是查杀给 7 ——
**同一个验人目标，两种结果对应两个不同的去向**。所以实际存的是：

```
警徽流 = [
   {"验": 3, "金水给": 3, "查杀给": 7},
   {"验": 5, "金水给": 7, "查杀给": 0},   ← 0 = 撕毁
]
```

Scratch 里用三条平行列表表达（`验人 / 金水去向 / 查杀去向`），索引对齐。

### 判定函数（死亡时调用一次）

```
处理警徽(死者):
    若 警徽持有者 ≠ 死者 → 返回            // 死的不是警长
    若 死者已撕毁 → 返回
    若 警徽流_指针 > 长度(验人) →
        警徽流失; 返回                      // 没留流，直接流失
    p = 警徽流_指针
    目标 = 验人[p]
    结果 = 查验结果[目标]                   // 1=金水 2=查杀 3=具体身份
    若 结果 = 1 → 新 = 金水去向[p]
    否则       → 新 = 查杀去向[p]
    若 新 = 0 → 警徽流失                     // 撕警徽
    否则若 存活[新] = 0 → 警徽流失            // 接收人已死 → 顺延下一位? 见下
    否则 → 警徽持有者 = 新
```

⚠️ **「接收人已经死了」怎么办** —— 这是真实对局里高频出现的 bug：

- 严格规则：**警徽流失**（预言家没算到这一步）
- 常见房规：**顺延到下一个存活的金水**（更友好）

**选一种并写进规则说明**。最差的做法是「程序随机选一个」——
玩家会发现警徽莫名其妙飞到一个陌生人手里。

⚠️ **自爆会让警徽流作废**（§340）：如果警长在自爆发生前就死了，正常结算；
如果自爆发生在警长死亡之后、警徽移交之前，**先移交再入夜**。

## §339 自爆：狼人的「终止键」

**规则**：狼人可以在**白天任意时刻**（包括自己发言时、别人发言时、投票前）公开自爆身份。

```
自爆效果：
① 立即中止当前所有发言
② 自爆者出局（有遗言，官方 30 秒）
③ 直接进入黑夜（跳过剩余的投票环节）
④ 当天的放逐投票取消
⑤ 若在警长竞选期间自爆 → 触发「吞警徽」（§341）
```

**自爆是狼人最核心的战术**，因为它能：
- 打断预言家的发言（避免信息扩散）
- 跳过对自己不利的投票
- 用一条命换掉一个白天

### 四种自爆变体

| 身份 | 自爆额外效果 |
|---|---|
| **普狼 / 狼王 / 狼美人等** | 仅基础效果 |
| **白狼王** | 自爆时**可带走一人** |
| **血月使徒** | 自爆后**当晚所有好人技能被封印**；若是最后一个被放逐的狼，**存活到下一个白天天亮后才出局** |
| **觉醒白狼王** | 白天可**诱导**一名玩家自爆；被诱导者可再带一人；**双方均有遗言** |

⚠️ **不能自爆的身份**：狼美人、恶灵骑士、石像鬼、隐狼、狼鸦之爪、寂夜导师、蚀日侍女、寻香魅影、猩红狼王、觉醒隐狼、觉醒狼美人。
判定用 `可自爆` 字段（§329 的位掩码思路），不要硬编码。

### 代码骨架

```
自爆(玩家):
    若 身份[玩家] 的 可自爆 = 0 → 返回 "该身份不能自爆"
    若 已出局[玩家] = 1 → 返回
    白天阶段 = 0                       // 中止发言
    附加效果(玩家)                      // 白狼王带人 / 血月封印
    死亡(玩家, 死因=自爆)                // 死因=7，不可开枪（除白狼王主动带人）
    若 在竞选期间 → 吞警徽(单爆/双爆)
    阶段 = 夜晚
    夜次 = 夜次 + 1
```

⚠️ **`死因 = 自爆` 必须单独一个编码**。如果复用「放逐」，
猎人在自爆时会被判定成「可开枪」（因为放逐可开枪），直接规则错误。

## §340 吞警徽：单爆与双爆

自爆发生在**警长竞选期间**时，规则有两种流派，**必须在板子开关里选**：

### 单爆吞警徽（简单版）

```
竞选期间任意狼人自爆 → 警徽直接流失，本局全程无警长
```

### 双爆吞警徽（官方默认版）

```
第一次自爆：
    竞选暂停 → 宣布死讯 → 死者遗言 → 进入黑夜
第二次自爆（次日白天恢复竞选后）：
    警徽流失 → 宣布死讯（此时死者无遗言）→ 进入第三夜
```

**双爆的关键细节**：
- 次日恢复竞选时，**直接进入退水环节**并投票（不重新发言）
- 第二次自爆后，**死者的遗言被取消**（因为流程被压缩）
- 如果只自爆一次，**竞选继续**，警长照常产生

⚠️ 双爆是官方默认，很多开源实现只做了单爆 —— 这就是「玩起来感觉不对」的来源之一。
在 `板子开关` 里放一个 `双爆吞警徽` 位，两种都能跑。

## §341 遗言规则：一张表说清

| 死因 | 有遗言？ | 时长 |
|---|---|---|
| **首夜**被刀 / 被毒 / 任何夜间死亡 | ✅ 有 | 官方 120 秒 |
| **第 2 夜及以后**的夜间死亡 | ❌ **没有** | — |
| **白天**被放逐 | ✅ 有 | 120 秒 |
| **白天**被枪 / 被决斗 / 被技能 | ✅ 有 | 120 秒 |
| **自爆** | ✅ 有 | **30 秒** |
| **被白猫延迟死亡** | 按最终死亡时点判定 | — |
| **被摄梦人连带** | 按夜间死亡规则（仅首夜有） | — |
| **被诱导自爆（觉醒白狼王）** | ✅ 双方都有 | 30 秒 |

**一句话记忆**：**「夜里只有第一晚能说话，白天死的人都能说话，自爆只给 30 秒。」**

⚠️ **遗言是「死亡结算完之后」才发布的**。如果边死边发遗言，
会出现「猎人先开枪带走一个人，然后才发遗言」的顺序错乱 ——
正确顺序是：`收集死亡 → 结算技能链 → 统一公布 → 依次遗言`。

## §342 夜间行动顺序（完整队列）

这个顺序比第三十一册 §299 的简版长得多，因为身份多了。原则不变：
**防守 → 狼刀 → 救人 → 情报 → 收尾**。

```
第 0 位  魔术师          交换号码牌（必须最先，之后所有技能按新号码）
第 1 位  炼金魔女        未明之雾（限制狼刀目标）
第 2 位  奇迹商人        给幸运儿技能
第 3 位  噩梦之影        恐惧（可能封锁整个狼队）
第 4 位  蚀时狼妃        封锁（影响后续技能的目标）
第 5 位  蚀日侍女        吞噬（获得技能并当晚使用）
第 6 位  守卫 / 流光伯爵 / 觉醒守卫（夜间守护）
第 7 位  狼人阵营        狼刀 + 狼技（狼美人魅惑、蓝狼双刀、夜之贵族夜仆…）
第 8 位  女巫 / 觉醒女巫  解药 / 毒药
第 9 位  预言家 / 魔镜少女 / 纯白之女 / 觉醒预言家 / 狼巫 / 石像鬼 / 守墓人
第 10 位 猎魔人 / 追魂者 / 乌鸦 / 子狐 / 白昼学者 / 寂夜导师 / 摄梦人 / 白兔
```

**为什么蚀日侍女在第 5 位**：她要「吞噬并获得技能，当晚使用」。
如果排在第 9 位之后，她吞到的查验技能当晚就用不了了。

**为什么子狐在最后**：她的效果是「让狼队当夜不能袭击」——
听起来应该在最前，但官方判定是「当夜已发生的狼刀不取消」还是「整夜禁止」，
**按板子说明书**。实现时最安全的做法是：子狐在狼刀前（第 5.5 位），
且用 `狼刀被封锁` 标志位，而不是回滚已发生的行动。

⚠️ **「每个身份醒来第一件事是检查自己是否存活」** —— 这条在第三十一册说过，
但身份一多就更容易漏。建议做成**统一入口**：

```
夜间行动(身份, 玩家):
    若 存活[玩家] = 0 → 返回           // 死人不能行动
    若 技能被封锁[玩家] = 1 → 返回      // 被恐惧/削弱
    若 技能已用完[玩家] = 1 → 返回
    执行身份技能
```

## §343 死亡结算与技能链

夜间可能同时有多人死亡，**必须收集完再统一结算**，否则会互相干扰。

### 收集阶段

```
今晚死亡 = []
若 狼刀命中 且 无有效保护 → 加入
若 女巫毒 → 加入
若 猎魔人狩猎失败 → 猎魔人加入
若 摄梦人夜间出局 → 梦游者加入
若 狼美人出局 → 昨夜被魅惑者加入
若 猩红狼王出局 → 所有被附着者加入
若 夜仆到期 → 加入
```

### 结算阶段（顺序敏感）

```
① 先算「免疫」
   豁免名单 = 守卫 / 解药 / 流光庇护 / 觉醒守护 / 梦游者 / 恶灵骑士(免疫夜死)
   奶穿：守卫 且 解药 同时作用于同一人 → 该人仍然死
② 再算「连带」
   摄梦人死 → 梦游者死（即使梦游者本来免疫）
   狼美人死 → 被魅惑者死
   猩红狼王死 → 附着者死
   情侣一方死 → 另一方死
③ 再算「反伤」
   恶灵骑士被预言家查验 → 预言家次日死
   恶灵骑士被女巫毒 → 女巫次日死
   狼巫验到纯白之女 → 纯白之女死
   纯白之女验到狼 → 该狼死
④ 最后算「触发式技能」
   猎人 / 狼王 / 觉醒猎人 → 询问是否开枪（受死因限制）
   白猫 → 延迟死亡
```

⚠️ **顺序错会导致「死人开枪杀活人」或「被毒的人还能开枪」**。
最典型：把 ④ 放在 ① 之前，猎人被毒了还开枪 —— 因为「免疫检查」还没跑完。

⚠️ **连带死亡不能再触发连带**：狼美人带走了 A，A 恰好是被摄梦的梦游者，
梦游者死亡又触发摄梦人？——**不会**，因为摄梦人可能已经死了。
规则上「连带死亡不产生新的连带」，代码里用一个 `连带深度 > 0 就跳过连带判定`。

## §344 胜负判定：屠边 / 屠城 / 第三方

### 三种胜负模型

| 模型 | 狼人胜利条件 | 好人胜利条件 | 用在 |
|---|---|---|---|
| **屠边** | 神职**全部**死亡 **或** 平民**全部**死亡 | 狼人全部死亡 | 12 人主流板子 |
| **屠城** | 好人**全部**死亡 | 狼人全部死亡 | 6 人萌新场、8 人诸神黄昏 |
| **第三方** | — | — | 丘比特情侣、混血儿 |

### 判定骨架（顺序不能换）

```
判定胜负():
    ① 若 第三方条件达成 → 返回 "第三方胜"
    ② 若 存活狼数 = 0 → 返回 "好人胜"
    ③ 若 屠边:
         若 存活神数 = 0 或 存活民数 = 0 → 返回 "狼人胜"
       否则若 屠城:
         若 存活好人数 = 0 → 返回 "狼人胜"
    ④ 返回 "继续"
```

**「或」是屠边的灵魂**：狼人只要杀光一边就赢，不需要两边都杀。
这条让狼人的策略变成「集中屠一边」，也让好人的策略变成「保护弱的那边」。

⚠️ **`存活民数 = 0` 时要看总民数**：8 人诸神黄昏没有民，
`存活民数` 恒为 0，会**开局就判狼人胜**。必须加：

```
若 总民数 > 0 且 存活民数 = 0 → 狼人胜
若 总神数 > 0 且 存活神数 = 0 → 狼人胜
```

⚠️ **白痴的特殊性**：白痴被放逐翻牌后**仍然存活**（只是不能投票），
所以不能算进「死亡」。如果把他算死，好人会提前输掉。

⚠️ **白猫的特殊性**：白猫「额外存活至下次放逐投票后」——
在被延迟的这段时间里，他**仍然算存活**。

## §345 状态机实现：阶段 × 子阶段

狼人杀是**两级状态机**，用两个变量而不是一个：

```
阶段   = 1 夜晚      2 白天讨论    3 投票    4 结算
子阶段 = 夜内的身份序号（1..11）
```

**为什么不用一个变量**：如果用一个变量枚举「夜晚-狼人」「夜晚-女巫」「白天-发言」…
状态数会爆炸（11 个夜间身份 × 多个白天阶段 = 30+），而且加一个身份就要加状态。

**用两个变量**，加身份只需要在夜间队列里插一行。

### 主循环骨架

```
当收到 [开始游戏]:
    发牌 → 校验板子 → 初始化
    阶段 = 1; 夜次 = 1
    广播 [夜晚开始]

当收到 [夜晚开始]:
    子阶段 = 0
    重复执行直到 子阶段 > 夜间队列长度:
        子阶段 = 子阶段 + 1
        广播 [夜间行动]        // 各角色收到后判断「是不是轮到我」
    广播 [天亮结算]

当收到 [天亮结算]:
    结算死亡 → 公布死讯 → 判定胜负
    若 未结束 → 阶段 = 2 → 广播 [白天开始]

当收到 [白天开始]:
    若有警长且首日未选 → 广播 [警长竞选]
    否则 → 广播 [发言阶段]
```

⚠️ **「广播 [夜间行动] 让各角色自己判断轮次」比自己调度好**：
Scratch 的广播是并行的，用「子阶段 = 我的序号」做守卫，天然就是队列。
自己写调度反而要维护「当前该谁」的指针，容易死循环。

## §346 投票、平票与 PK

```
投票统计(票箱, 存活):
    计数 = []                          // 长度 = 玩家数，全 0
    对 i = 1..长度(票箱):
        目标 = 票箱[i]
        若 存活[目标] = 0 → 跳过        // ① 死人不能被投
        若 投票者[i] 已死 → 跳过         // ② 死人不能投票
        计数[目标] = 计数[目标] + 1
        若 投票者[i] = 警长 → 计数[目标] + 0.5   // ③ 警长 1.5 票
    最高 = 0
    对 i = 1..长度(计数):                // ④ 单独扫一遍求 max
        若 计数[i] > 最高 → 最高 = 计数[i]
    若 最高 = 0 → 返回 "无人出局"
    并列 = [所有 计数[i] = 最高 的 i]     // ⑤ 返回全部并列者
    返回 并列
```

这五条在第三十一册 §299 讲过三条（①④⑤），这里补两条：
**② 死人不能投票**、**③ 警长 1.5 票**。

### 平票处理

```
若 长度(并列) = 1 → 出局
否则:
    PK 发言（只有并列者发言）
    重投（只有「未参与 PK」的人能投票）
    若 再次平票 → 无人出局，直接入夜
```

⚠️ **PK 时能不能投自己**？规则上**可以**（并列者互相投票），但**不能投非并列者**。
实现里用一个 `可投集合 = 并列者` 过滤。

## §347 发言顺序

| 情况 | 顺序 |
|---|---|
| 有警长，1 人死亡 | **死左 / 死右**（死者左右第一个存活者起） |
| 有警长，平安夜或多死 | **警左 / 警右**（警长左右第一个存活者起） |
| 无警长 | 死左 / 死右 |
| 警长竞选 | **随机**顺序（官方）；或从最大/最小号起（房规） |
| 警长发言位置 | **最后一个发言**（归票权） |
| 次日 | **换手**（昨天从左，今天从右） |

**实现：只需要一个「方向」变量 + 一个「起点」变量。**

```
下一个发言者(当前):
    重复 人数 次:
        当前 = 当前 + 方向
        若 当前 > 人数 → 当前 = 1
        若 当前 < 1 → 当前 = 人数
        若 存活[当前] = 1 → 返回 当前
```

⚠️ **换手用 `方向 = -方向`**，不要另外记「今天是左还是右」——
两个变量会不同步。

## §348 AI 玩家、平衡与校验

### AI 决策：三档就够

| 难度 | 狼人 | 好人 |
|---|---|---|
| 简单 | 随机刀存活好人；不自爆 | 随机投票 |
| 普通 | 优先刀「跳预言家」的人；被查杀时自爆 | 跟着预言家的查杀投 |
| 困难 | 计算屠边进度，优先补齐缺的一边 | 结合查验/投票记录算狼坑 |

**别做搜索**：狼人杀的博弈树是「不完全信息 + 高分支」，搜索一定爆炸。
**加权打分**（威胁度 × 屠边价值）就足够像人。

### 平衡：轮次计算

```
好人轮次 = 神数 + 民数          // 好人能承受的死亡次数
狼人轮次 = 狼数                 // 狼人能承受的放逐次数
```

屠边局的平衡点：**狼刀速度 ≈ 好人放逐速度**。
12 人标准场 4 狼 8 好人，狼人每晚杀 1、好人每天投 1，
理论上狼人 4 天杀完 8 人中的 4 个（屠一边），好人 4 天投完 4 狼 —— 接近五五开。

**加一个强力神（女巫/守卫）= 好人 +1 轮次**，所以要减一个民或加一狼。
这条经验能帮你判断「自制板子是不是一边倒」。

### 校验清单（做狼人杀作品必跑）

| # | 断言 | 抓什么错 |
|---|---|---|
| 1 | 板子池长度 = 人数（盗贼局 +2） | 少发/多发牌 |
| 2 | 身份计数与配置表一致 | 手写池子漏一张 |
| 3 | 洗牌两次顺序不同 | 洗牌没生效 |
| 4 | 预言家验隐狼 → 返回好人 | 隐狼白设计 |
| 5 | 守卫 + 女巫同目标 → 该人死 | 奶穿丢失 |
| 6 | 女巫不可自救 | 自奶 bug |
| 7 | 猎人被毒 → 不能开枪 | 死因表缺失 |
| 8 | 只有 1 人上警 → 直接当选 | 竞选死循环 |
| 9 | 0 人上警 → 警徽流失 | 状态 7 未实现 |
| 10 | 平票 → PK → 再平 → 流失 | PK 逻辑缺失 |
| 11 | 警徽交给 X → X 是金水 | 警徽流未实现 |
| 12 | 撕警徽 → 最后一次验是查杀 | 同上 |
| 13 | 自爆 → 跳过投票直接入夜 | 自爆只当死亡处理 |
| 14 | 双爆 → 警徽流失 | 只做单爆 |
| 15 | 屠边：杀光一边即胜 | 写成屠城 |
| 16 | 无民板子不误判 | `存活民数=0` 恒真 |
| 17 | 白痴翻牌后仍算存活 | 被算死导致提前输 |
| 18 | 连带死亡不递归 | 无限循环 |

### 十二个坑

1. **板子池长度 ≠ 人数** —— 盗贼局要 `+2`，其余不能多。
2. **只做 4 个身份** —— 玩家三分钟看穿，必须至少覆盖主流 20+。
3. **隐狼被验成狼** —— 查验函数没先判隐狼。
4. **奶穿丢失** —— 用 `if 守卫 or 解药 then 活` 简化模型。
5. **死人能投票 / 死人能被投** —— 统计前没过滤。
6. **平票只取第一个人** —— 求 max 时边统计边比。
7. **警徽流没实现** —— 警长死了就没了，玩家最直接的「这游戏不完整」感受。
8. **接收人已死时随机选** —— 玩家会发现警徽飞到陌生人手里。
9. **自爆复用「放逐」死因** —— 猎人被自爆时错误地能开枪。
10. **只做单爆吞警徽** —— 官方是双爆。
11. **夜间行动不检查存活** —— 死人开药。
12. **边死边发遗言** —— 技能链和遗言顺序错乱。
