# 第十三册：教育课件通用范式（含数据可视化）（§121–§126）

> 面向「微课、互动课件、教学演示、随堂测验、数据图表作业」类作品的一整套可照抄范式。
> 配套可运行工程：`examples/edu_demo.yaml`（翻页 + 柱状图数据可视化 + 随堂测验）、
> 行为校验 `scripts/edu_behavior_check.mjs`、生成器 `deploy-tools/gen_edu.py`。
>
> **本册所有结论都经过 scratch-vm 实跑验证**（`EDU_LOGIC_OK`），不是纸上推演。
> §126 的五个坑是会真实让「翻页乱跳 / 图表画不出来 / 无头校验全绿但逻辑错」的，务必先看。

## 121. 数据模型与交互总览

课件不是「一堆文字造型」，而是 **若干页 + 一组数据 + 一组交互状态**。所有翻页、图表、判题
都是对变量/列表的变换，角色只是把状态画出来。

### 关键变量（stage 全局）

| 变量 | 作用 |
| --- | --- |
| `页码` | 当前页（1-based），翻页只改它 |
| `总页` | 总页数，翻页边界夹紧用 |
| `得分` | 随堂测验累计分 |
| `当前答案` | 学生当前选的选项（1..4），由选项按钮置位 |
| `正确答案` | 本题正确答案编号，判题时与 `当前答案` 比较 |

### 列表与角色

| 列表/角色 | 作用 |
| --- | --- |
| `数据` | 图表数据源（如 `[5,8,3,9,6]`），块式声明 |
| `柱子` 角色 | 数据可视化：每个数据点一个克隆，高度由 `数据[编号]` 驱动 |
| 翻页/选项按钮 | 只广播意图（`[上一页]`/`[下一页]`/`[选项A..D]`），不直接改逻辑 |

### 广播链路

```
当绿旗被点击        → 复位 页码/得分/当前答案 + broadcast [生成柱子]
当收到[生成柱子]    → 仅本体：生成 N 个 柱子 克隆（N=数据长度）
柱子 当作为克隆     → 高度 = 数据[编号]；show
当收到[下一页]      → if(页码<总页) 页码+1
当收到[上一页]      → if(页码>1)   页码-1
当收到[选项A..D]    → 当前答案 = 1..4
当收到[提交]        → if(当前答案==正确答案) 得分+1
```

> 按钮「只广播、不直算」是最稳的交互范式：按钮造型可随便换，逻辑全在舞台，且
> 无头校验能用 `broadcast` 精确模拟点击（见 §126.1）。

## 122. 课件结构：封面 / 分页 / 翻页

一节课 = 多页。用 `页码` 变量 + 两个翻页广播实现，绝对不要给每一页单独写一堆 `if`。

```text
当绿旗被点击        → 页码 = 1；得分 = 0；当前答案 = 0；broadcast [生成柱子]
当收到[下一页]      → if (页码 < 总页)  页码 = 页码 + 1
当收到[上一页]      → if (页码 > 1)     页码 = 页码 - 1
```

**显示哪一页**：每个内容角色 `当收到[刷新]`（或每帧 `forever`）里按 `页码` 切造型 / 显隐：

```text
当收到[刷新]        → if (页码 == 1) 切换造型[封面]  else 切换造型[讲解]
                   → if (页码 == 我的页号) show  else hide
```

> 边界必须夹紧（`< 总页` / `> 1`），否则翻到 0 页或 总页+1 页会显示空白。

## 123. 知识点讲解：文字牌 / 分步演示

- **文字内容放列表，不放造型**：`讲解词` 列表第 `页码` 项就是要展示的句子，改词只改列表。
- **分步演示**：用一个 `步数` 变量，点「下一步」`步数+1`，各元素按 `步数` 显隐，
  实现「一点一点展开」的推导过程（数学证明、实验步骤都好用）。
- **别用 `say`/`think` 气泡**当正式讲解框（气泡会被遮挡、样式不可控、无头测不到）；
  用自制「文字牌」角色（见第九册 §?? / 通用铁律 §4：对话用自制聊天框角色）。

## 124. 数据可视化：柱子克隆 + 列表驱动高度

把「数据」画成图，**核心是可被无头校验断言**。用克隆 + 列表驱动一个**可见变量**
（高度/位置），而不是 `set size`（无头看不到 size 变化）或画笔轨迹（无头看不到笔迹）。

```text
当收到[生成柱子]    → if (是克隆 == 0)              # ★ 克隆守卫，防指数爆炸
                         repeat (数据长度):
                             编号 = 编号 + 1
                             create clone of [myself]
柱子 当作为克隆     → 是克隆 = 1
                       高度 = 数据[编号]             # ★ 高度取自列表，且是可见变量
                       show
```

校验时只要断言「`柱子` 克隆数 == 数据长度」且「每个克隆的 `高度` == `数据[编号]`」即可，
完全不依赖渲染器。

### 变体

| 图表 | 改法 |
| --- | --- |
| **饼图** | 每个扇区一个克隆，`大小` 由 `数据[i]/总和` 决定（用变量而非 size 视觉） |
| **折线图** | 每个数据点一个克隆，`x`/`y` 由 `数据[i]` 映射；连线用「点 + 细长方块」拼，或画笔（仅肉眼，不进校验） |
| **热力/分数条** | 克隆 `颜色` 由数值映射（改 `切换造型` 或变量阈值） |
| **实时数据** | `数据` 列表由传感器/答案统计实时 `replace`，柱子 `forever` 每帧重读 `高度` |

> 任何图表都遵循同一铁律：**数据在列表、呈现状态在可见变量**，这样「图对不对」能用
> 行为校验自动证明，而不是靠人眼截图。

## 125. 随堂测验：复用答题范式（§106–§110）

课件末尾的 quiz 直接套用第十册答题系统：四态状态机 + 平行列表题库 + 索引判题 +
防连点锁。`edu_demo` 里给了一个最小版：

```text
当收到[选项A] → 当前答案 = 1
当收到[选项B] → 当前答案 = 2
当收到[选项C] → 当前答案 = 3
当收到[选项D] → 当前答案 = 4
当收到[提交]  → if (当前答案 == 正确答案)  得分 = 得分 + 1
```

**判题绝不比文本**，只比编号（`当前答案 == 正确答案`）；题库加题只加列表项，脚本不改。
完整四态/防连点/越界处理见 `references/quiz-systems.md`。

## ★ 126. 五个致命坑（实测复现过，不是理论）

### 126.1 翻页/答题用「广播+变量」，别用 `ask`/`answer`

`ask` 会阻塞脚本、样式不可控、且**无头 scratch-vm 测不到**（没有输入框）。
正确做法：每个选项一个角色按钮，点哪个就 `广播[选项X]` 并置 `当前答案`。这样
无头校验能直接 `broadcast` 模拟点击并断言 `得分`，四层校验看不见的逻辑错也能抓到。

### 126.2 数据可视化用「克隆+列表驱动可见变量」，别用 `set size` / 画笔轨迹

- `set size` 的赋值在 `if (this.renderer)` 内，**无头环境看不到变化**（SKILL.md 无头盲区）；
- 画笔笔迹同理，无头测不到。
✅ 让每个图表元素是一个克隆，把它的「高度/位置/颜色」写进**可见变量**，
再用 `change y` / `切换造型` 呈现。校验只读变量即可，100% 可验。

### 126.3 列表必须块式声明（同 §120.3）

`数据` 这类列表在 builder 里是「变量存数组」，必须用块式 YAML（`- 5` 每行一个）。
行内式 `[5,8,3,9,6]` 会被误当成逗号拼接的字符串变量，数组语义全失，图表读不到值。

### 126.4 克隆守卫必须有（同 §120.5）

`[生成柱子]` 这类「生成 N 个克隆」的广播，必须 `if(是克隆==0)` 守卫——
否则每个克隆也会响应生成广播，数量指数爆炸、超出 300 克隆上限被静默丢弃。

### 126.5 文案/答案别硬编码进造型，放列表/变量

题目、讲解词、正确答案都放列表/变量。加一页/加一题只改数据，脚本一行不动。
硬编码进造型会导致「换词要改代码、无头无法校验内容正确性」。

## 变体与扩展

| 玩法 | 改法 |
| --- | --- |
| **多章节大课件** | `章` + `页` 两级变量；`总页` 按章动态算 |
| **闯关解锁** | 上一页 `提交` 得分达标才允许 `下一页`（在 `[下一页]` 里加 `if(得分>=阈值)`） |
| **错题本** | 答错的题号写进 `错题` 列表，结尾遍历重做 |
| **学生数据看板** | 全班答案汇总进 `数据` 列表，`柱子` 直接画出正确率分布（复用 §124） |
| **互动拖拽** | 拖拽用 `当角色被点击` + `go to [鼠标]`（仅肉眼，不进校验）；落点判定用坐标区间 |

> 无论哪种变体，**§126.1 的广播交互**、**§126.2 的可见变量图表**、**§126.4 的克隆守卫**
> 都适用，且图表/测验必须靠行为校验实跑验证。

## 交付前自检

```bash
python scripts/build_sb3.py --ir examples/edu_demo.yaml --out examples/output/edu_demo.sb3 --workdir /tmp/edu_build
python scripts/validate_sb3.py --sb3 examples/output/edu_demo.sb3      # 四层
node scripts/edu_behavior_check.mjs examples/output/edu_demo.sb3         # EDU_LOGIC_OK
```

`edu_behavior_check.mjs` 会真实模拟「绿旗生成 → 检查 页码=1/得分=0/柱子数=数据长度 →
每根柱子高度==数据值 → 翻页 页码 1→2→1 → 答对得分、答错不加分」，全部断言通过才输出
`EDU_LOGIC_OK`。

**只过四层校验不算课件作品完成**——翻页、图表数据对应、测验计分这三条核心逻辑
必须靠行为校验实跑验证。
